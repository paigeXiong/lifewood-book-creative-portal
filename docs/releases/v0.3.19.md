# Book Creative Portal v0.3.19

## 更新 / Changes

- 新增定时任务页面，可直接创建定时公告、预约已有草稿、取消预约或提前发布，并查看执行记录；负责人可查看备份计划与执行记录。
- 公告管理移至项目运营，管理员及运营人员可管理公告，无需授予系统配置权限。
- 客户顶部公告滚动展示标题与正文，支持暂停、详情及按账号持久关闭；关闭状态跨设备保留。
- 邮件服务增加持久化滚动发送额度，默认每分钟 10 次、24 小时 200 次，测试与失败尝试共用额度；达到额度后排队等待。
- 邮件模板支持预览未保存内容、离开前保护修改及模板操作审计。
- 从项目列表进入详情后，返回保留搜索、筛选、排序和页码。
- 帮助中心同步中英文教程与排障说明，现有客户文档 13 篇、管理文档 18 篇。

- Add scheduled tasks with direct announcement creation, scheduling existing drafts, cancellation, early publication and execution history; owners can inspect backup schedules and runs.
- Move announcement management to Project operations with independent administrator and operator permissions.
- Scroll announcement titles and bodies in the customer banner, with pause, details and persistent per-account dismissal across devices.
- Persist rolling SMTP quotas, defaulting to 10 attempts per minute and 200 per 24 hours. Tests and failed attempts share the quota; queued mail waits when limited.
- Preview unsaved email templates, protect pending edits and audit template actions.
- Preserve project list search, filters, sorting and pagination when returning from details.
- Update bilingual help tutorials and troubleshooting: 13 customer and 18 administration articles.

## 使用与升级 / Usage and upgrade

- 定时任务入口：项目运营 → 定时任务 → 创建定时公告 → 保存并设置发布时间。保存草稿后仍须确认预约；后台服务需要持续运行，停机错过的预约恢复后补执行。
- 公告受众和有效期按实际发布时间确定。预约后先取消预约才能修改内容。升级不会自动创建公告任务或启用备份计划。
- 邮件限额不会因重启或更换发件人清零；平台限额不等同于邮箱服务商的发送许可。
- 升级前备份数据目录，保留数据库、上传文件、配置和数据保护密钥。正式域名、生产邮件服务与业务工作流仍需部署配置及验收。

- Open Project operations → Scheduled tasks → Create scheduled announcement → Save and set publication time, then confirm the schedule. The backend must remain running; missed jobs run after recovery.
- Recipients and validity start at actual publication. Cancel a schedule before editing content. Upgrading does not create announcement jobs or enable backup policies.
- Mail quota usage survives restarts and sender changes. Platform limits do not replace the mail provider's restrictions.
- Back up and retain databases, uploads, configuration and data-protection keys before upgrading. Production domains, email delivery and business workflows still require deployment configuration and acceptance.
