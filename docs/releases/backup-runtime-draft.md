# 备份恢复与运行配置更新（发布草稿）

本草稿已合并至 [v0.3.12 发布说明](./v0.3.12.md)。最终范围及验证以该说明和发布验收记录为准。

## 功能更新

- 系统配置新增备份管理：手动与定时备份、保留策略、分页筛选和受权限保护的下载。
- 支持独立进程的后台恢复：恢复前预检、确认、安全备份、重启恢复及启动失败自动回退。
- 新增恢复记录：按结果筛选，查看操作人、目标时间、失败说明并下载恢复前安全备份。
- 新增独立校验入口：后台检查整包与文件清单，保存检查结果，支持中断后重试。
- 运行配置支持后端、客户页面和管理后台的协议、地址与端口；增加运行健康与存储状态。
- 审计支持可读对象、变更详情和 CSV 导出，配置说明按需通过问号查看。

## 稳定性与验证

- 恢复过程清理旧会话，保留当前监听配置与备份策略；恢复失败时保留明确的回退或人工处理状态。
- 校验结果保存失败会明确提示，避免把未持久化结果显示为通过。
- 配额扫描可处理枚举后文件消失的情况，其他读取错误仍阻止继续上传。
- Windows 验证和发布流程加入真实原生程序恢复及启动失败回退演练。
- 客户门户和后台保持中文、英文及移动端适配。

## 部署说明

- 自动备份默认关闭；手动和恢复前安全备份不会被自动保留策略删除。
- 后台恢复适用于独立进程；Windows 服务与 systemd 继续使用停机恢复流程。
- 归档包含账号及客户资料，目前未加密、未自动复制异地；应按部署要求保管。
- 保存监听设置后需按部署方式重启才能应用；本地开发通过启动脚本更新三项服务。
- 邮件通知不在本次更新范围。Linux 本机未验证，需对应架构 CI 与演练通过。

详细操作见 [备份管理](../managed-backups.md)、[部署与恢复](../deployment-and-backup.md)。
