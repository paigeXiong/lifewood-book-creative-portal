# Lifewood · Deseret Book v0.3.12

## 更新内容

- 新增后台备份管理：手动、定时备份，保留策略、分页筛选、下载及独立完整性校验；校验结果持久化，支持中断重试。
- 新增恢复预检、恢复前安全备份、独立进程恢复、启动失败自动回退及恢复历史；恢复后旧会话失效，当前监听配置与备份策略保留。
- 运行设置支持后端、客户门户和管理后台分别配置协议、监听地址与端口；补充运行健康、磁盘和存储状态，说明改为按需查看。
- 审计增强：展示可读对象与变更详情，支持筛选及 CSV 导出。
- 组织管理自动生成 6:1 横向文字标识，支持中英文、长名称及改名同步更新，保留查看组织成员的入口。
- 优化设置页导航图标与滑动选中效果；稳定任务列表切换时的列宽、滚动条及筛选控件，统一工具栏按钮尺寸。
- 重整个人资料页，联系信息按需编辑；统一客户和后台账号菜单及头像姓名整体样式，后台头像和资料入口统一跳转个人资料页。
- 完成前端用户输入注入审查，补齐参考链接、附件链接的协议白名单，新增恶意 HTML、危险 URL 和中英文页面回归测试。
- 修复存储配额扫描中文件消失引发的失败，并加强恢复、校验结果保存及异常回退验证。

## Changes

- Add managed manual and scheduled backups, retention policies, filtered pagination, downloads and persistent integrity verification with retry after interruption.
- Add restore preflight, safety backups, standalone-process recovery, startup failure rollback and restore history. Restores revoke old sessions while preserving current listener settings and backup policies.
- Configure protocol, listen address and port separately for the API, customer portal and admin portal. Add runtime health and storage visibility with on-demand help.
- Improve audit records with readable targets, change details, filters and CSV export.
- Generate deterministic 6:1 organization wordmarks, including Chinese names, long-name handling and automatic updates after renaming.
- Add settings navigation icons and sliding selection, stabilize task-table columns across filtering, and align toolbar action sizes.
- Refine the profile page with on-demand contact editing. Share account-menu and avatar/name capsule styling across both portals, and route admin profile links to the profile page.
- Review untrusted frontend content rendering and reinforce URL allowlists for references and attachments, with HTML-injection and bilingual browser regression coverage.
- Handle files disappearing during storage quota scans and strengthen backup verification, restore and rollback regression checks.

## 部署与范围 / Deployment and scope

- 自动备份默认关闭；手动备份和恢复前安全备份不会被自动保留策略删除。归档尚未加密或自动异地复制，需妥善保管。
- 后台在线发起恢复适用于独立进程。Windows 服务及 systemd 仍使用停机恢复流程；保存监听配置后需重启相应服务才能生效。
- Scheduled backups are disabled by default. Automatic retention does not remove manual or restore-safety backups. Archives are not encrypted or automatically replicated offsite.
- Managed restore applies to standalone processes. Windows services and systemd use the offline restore procedure. Listener changes require restarting the relevant services.
- 本次不包含邮件通知、短信或视频生产工作流。/ Email, SMS and production video workflows are not included.
- Windows ZIP、中英文 MSI、Linux x64/ARM64 包附 SHA-256 校验文件，全部构建完成后公开。/ Publication waits for Windows ZIP, bilingual MSI and Linux x64/ARM64 packages, each with SHA-256 checksums.
