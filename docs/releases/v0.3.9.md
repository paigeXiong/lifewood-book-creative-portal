# Lifewood · Deseret Book v0.3.9

## 更新内容

- 新增双语平台公告：登录前公开提示，登录后按账号保存收件与关闭状态。支持全部账号、语言偏好、指定组织投放、定时生效、下架及个人历史滚动加载；批量关闭避免触发写入限流。
- 完善后台配置管理：维护预设角色及图片，删除配置项时校验引用和并发版本；改进参考音色试听、上传与错误反馈。
- 优化客户项目列表、保存失败恢复、步骤导航和退回沟通，统一应用内确认弹窗，改善最终交付操作反馈。
- 补充中英文、移动布局、配置安全删除和从首次提交到成品下载的完整回归。

## Changes

- Add bilingual announcements with public pre-login notices, targeted account inboxes, durable dismissal, scheduling, withdrawal and paginated personal history. Bulk dismissal avoids excessive write requests.
- Add character preset management and guarded configuration removal; improve voice sample playback and upload feedback.
- Improve project lists, draft save recovery, revision navigation, in-app confirmations and delivery feedback.
- Expand bilingual, mobile, configuration and full customer-to-delivery regression coverage.

## 升级 / Upgrade

- 升级前备份数据库、附件及数据保护密钥，保留原数据目录。启动时自动补充公告、收件记录、角色预设和配置删除标记。
- Back up the database, uploads and data-protection keys. Keep the existing data directory; startup initializes announcement, recipient, preset and configuration-removal storage.
- 公告收件人按发布时确定；新账号不会收到旧公告。生产协作和端到端视频生成仍不在本次范围。
- Announcement recipients are fixed at publication. New accounts do not receive old notices. Production collaboration and end-to-end video generation remain outside this release.

## 验证 / Validation

- 本地完整回归：客户前端 196、管理端 57、服务端 160 项通过；后续批量关闭修复通过 6 项公告服务端和 2 项公告前端回归。
- 真实浏览器验证公告发布、公开语言筛选、23 条个人公告滚动加载及关闭持久化；Windows Native AOT 构建与启动冒烟通过。
- Android Quark has not been verified on a physical device in this release cycle; mobile Chromium viewport checks do not replace device testing.

## 发布资产 / Release assets

Windows x64 ZIP, zh-CN/en-US MSI installers, Linux x64/arm64 archives and SHA256 checksums.
