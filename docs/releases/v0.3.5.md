# Lifewood Book Creative Portal v0.3.5

本版本重点修复远程部署访问与 Windows 安装升级问题，使平台可以作为独立服务直接部署到局域网或服务器，并进一步完善双语 MSI 的安装、覆盖升级和数据保护能力。

## 主要更新

- 服务端不再把非本机 HTTP 请求误判为非法访问，可按配置直接监听 HTTP 或 HTTPS。
- 运行配置新增协议字段，管理后台可统一设置协议、监听地址和端口；旧配置保持兼容。
- Windows MSI 安装向导新增“仅本机”与“所有网络接口”监听范围选择，并提供中英文说明。
- MSI 安装后自动创建客户门户桌面快捷方式，以及客户门户和管理中心开始菜单入口。
- 中英文 MSI 支持相互识别和覆盖升级，避免本地化版本被当成两个独立产品。
- 修复旧版本将端口保存为 DWORD 后，升级读取成 `#5077` 并阻断安装的问题；升级后端口改为稳定的字符串格式。
- 覆盖安装和卸载继续保留数据库、上传附件、最终成品、密钥与审计待写数据。
- 安装载荷移除 PDB 和 map 调试文件，缩小安装包体积。
- Windows 启动脚本默认支持 `0.0.0.0` 监听，并输出本机与网络访问地址。
- 新增真实 Windows Installer 会话、AppSearch、端口条件、数据目录安全和 MSI 表结构回归测试。
- 所有新增配置、安装界面、提示和错误信息均提供简体中文与英文版本。
