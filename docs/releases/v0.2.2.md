# Lifewood Book Creative Portal v0.2.2

本次补丁版本集中改善客户门户和管理后台的移动端体验，并统一页面视觉层级。

## 主要更新

- 恢复项目配置阶段的连续进度线，并为手机端保留紧凑进度指示。
- 压缩向导标题、统计区域和面板留白，减少装饰性边框。
- 优化手机端新建项目悬浮按钮、安全区间距和底部操作栏。
- 将管理后台的用户、组织、审计及系统配置表格改为移动卡片布局。
- 修复音色配置在窄屏下的音频控件溢出和字段错位。
- 调整弹窗初始焦点，避免手机打开弹窗时自动唤起软键盘。
- 移动表格字段标签继续复用现有中英文 i18n 文案。

## 验证

- 客户前端：36 项测试通过，生产构建通过。
- 管理后台：23 项测试通过，生产构建通过。
- API：发布前验证通过。
- Windows AOT 与 MSI 安装包由发布流水生成并附加到 GitHub Release。

## 升级说明

本版本不修改生产数据结构。MSI 覆盖安装继续保留现有生产数据与运行配置。
