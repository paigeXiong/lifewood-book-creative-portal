# Lifewood Book Creative Portal v0.3.14

## 更新内容

- 新增客户“数据概览”页面：当前项目数量、状态分布、提交与成品发布趋势、活动日历、每日明细和近期项目。日历支持鼠标、键盘和触屏，活动越多颜色越深。
- 统计按当前账号权限与所选时区计算。首次提交从升级后开始可靠记录，较早历史缺失明确标注，不补造数据；本版不统计平均交付耗时。
- 客户端与管理端按账号语言偏好自动跳转，并保留页面路径、查询条件和定位。同步完善中文、英文与窄屏显示。
- 优化项目详情标题面板、进度摘要、封面与资料排版，加入可定位的分组导航；项目搜索支持输入防抖和中文输入法。
- 改善断网与刷新失败时的页面恢复，保留已加载资料和未保存输入；登录失效或权限撤销仍阻止访问。反馈提交增加超时与稳定重试，修复重复选图及图片替换失败问题。
- 完善通知搜索、日期筛选、批量已读范围及弹窗键盘焦点；将“手稿”等默认标签改为更清晰的“书籍正文”，保留管理员自定义配置。
- 优化项目查询与索引，补充混合负载和持续负载验证；完善最终成品发布回执不明确时的恢复与客户进度展示。
- 加强安装和恢复验证，覆盖 Windows 安装器生命周期、Linux 服务覆盖安装与失败回滚，以及备份目录准备。

## Changes

- Add a customer Overview page with current project counts, status distribution, submission and publication trends, an activity calendar, daily events and recent projects. Calendar interactions support mouse, keyboard and touch.
- Scope statistics to the signed-in account and selected time zone. Reliable first-submission tracking starts after upgrade; incomplete earlier history is labeled rather than estimated. Delivery-duration metrics are excluded.
- Redirect both portals to the account language preference while preserving paths, query parameters and anchors. Improve Chinese, English and narrow-screen layouts.
- Refine project detail headers, progress summaries, covers and submitted information, with section navigation and IME-aware debounced project search.
- Preserve cached information and unsaved edits during retryable refresh failures, while continuing to block expired sessions or revoked access. Add feedback deadlines and safe retry; fix screenshot reselection and failed replacement recovery.
- Improve notification search, date filters, bulk read scope and dialog keyboard focus. Clarify default book-text labels without overwriting administrator customizations.
- Improve project queries and indexes, document mixed and sustained load checks, and recover uncertain final-delivery publication responses.
- Extend Windows installer lifecycle, Linux service upgrade and rollback validation, and private backup directory preparation.

## 升级说明 / Upgrade notes

- 升级前备份数据库、上传文件、成品和数据保护密钥。首次启动自动初始化统计记录与索引；既有项目及自定义选项保留。
- Back up the database, uploaded materials, deliverables and data-protection keys before upgrading. Startup initializes activity tracking and indexes while preserving existing projects and custom options.
- 历史覆盖从该实例首次初始化统计功能时开始；已有可靠的再次提交与成品发布事件仍可显示。当前状态统计不受历史覆盖起点限制。
- History coverage starts when this instance first initializes activity tracking. Existing reliable resubmission and publication events remain visible; current-state counts are independent of the coverage date.
- Windows ZIP、中英文 MSI、Linux x64/ARM64 包及对应 SHA-256 文件，全部构建和校验成功后公开。
- Windows ZIP, Chinese and English MSI installers, Linux x64/ARM64 archives and SHA-256 checksums are published after package checks succeed.
