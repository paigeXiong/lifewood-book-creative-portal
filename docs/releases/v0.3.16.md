# Book Creative Portal v0.3.16

## 更新 / 2026-09-16

- 新增可配置的邮箱验证、找回密码和个人邮件通知开关，支持中英文邮件。后台提供邮件队列状态、脱敏记录及配置检查。
- 支持配置并同时启用多个 OIDC 身份服务，登录页提供其他登录方式，个人设置支持分别绑定和解绑；配置编辑增加未保存保护与冲突恢复。
- 完善个人资料、头像、密码、登录设备和邮件偏好的异常恢复：保留必要输入、避免重复提交，隔离账号切换和离开页面后的迟到响应。
- 改善反馈截图压缩与上传取消、失败后手动重试，保留原提交编号；完善通知筛选、历史导航和操作状态恢复。
- 将客户与后台的补充说明统一收进轻量问号浮层，保留必要的错误和确认信息；项目列表移除冗余项目编号。所有新增交互支持中文与英文。

## Changes

- Add configurable email verification, password recovery and optional email notifications, with localized messages and owner-only queue diagnostics.
- Support multiple concurrent OIDC providers, alternative sign-in options and per-provider account linking. Protect unsaved configuration and retain edits during conflict recovery.
- Harden profile, avatar, password, session and email-preference operations against duplicate submission, lost responses, navigation and account changes.
- Improve feedback screenshot cancellation and manual retry with the original submission identity. Restore notification filters, history and action state.
- Consolidate supplemental guidance into compact help popovers across customer and admin pages while retaining actionable errors and confirmations. Remove redundant project numbers from list cards. New interactions support Chinese and English.

## 升级说明 / Upgrade notes

升级前备份数据库、上传文件、成品与数据保护密钥，再使用既有安装/升级流程。邮件凭据通过部署环境配置，禁止提交仓库；密钥丢失会影响待发邮件解密和身份配置。现有用户不会自动验证邮箱或订阅邮件；OIDC 需由所有者配置后主动启用。

Back up the database, uploads, deliverables and data-protection keys before upgrading through the existing installation process. Configure mail credentials in the deployment environment, never in source control. Preserve encryption keys for queued mail and identity configuration. Existing users are not automatically verified or subscribed; OIDC requires explicit owner configuration and activation.
