# v0.2.0 — 客户提交与内部交付闭环

发布日期：2026-08-27

## 重点更新

- 新增完整管理员后台：项目跟进、负责人分配、状态与优先级调整、内部备注、用户管理、审计日志和系统业务配置。
- 新增最终成品交付：管理员可直接上传或撤回 MP4/MOV，客户可在已提交项目详情中下载最新成品。
- 新增 Windows MSI 安装器：安装时可配置服务端口和数据目录；覆盖安装、升级与卸载均不会删除生产数据。
- 改进客户资料提交：期望时长支持选择预设值或直接输入具体时长，草稿、提交快照和详情页完整保留实际内容。
- 完善后台动态配置：表单选项、文件类别和参考音色均可维护，并支持中英文显示内容。
- 完善真实账号体验：Cookie 会话、首次所有者建号、客户与管理员权限、密码修改/重置、锁定策略和服务端生成头像图片。

## 可靠性与安全

- 管理员写操作、文件上传、最终交付和审计查询均使用真实认证与 CSRF 防护。
- 增加上传取消、版本冲突、未保存修改、配置停用与旧草稿兼容处理。
- 增加数据库安全迁移、上传删除恢复、审计待写日志恢复、备份与恢复脚本。
- Native AOT 发布和运行冒烟测试通过。
- 客户前端 29 项、管理后台 21 项、平台 API 29 项自动化测试通过。

## 升级说明

- 可直接从 v0.1.0 覆盖安装升级。
- 升级时沿用既有生产数据目录，不会清除数据库、附件、最终成品、审计记录或数据保护密钥。
- 正式部署仍应配置 HTTPS、可信反向代理，并在升级前创建备份。

## 已知范围

- 本版本不包含 AI 生成功能、站内通知、邮件或短信通知。
- 已提交项目保持不可编辑；客户通过项目详情查看进度和下载最终成品。

## English summary

v0.2.0 completes the customer intake and internal delivery loop with a full administration center, user management, configurable form catalogs, final-video delivery, a data-preserving Windows MSI installer, editable custom duration values, audit recovery, and expanded bilingual UX. AI generation and notification features remain intentionally out of scope.
