# Lifewood · Deseret Book v0.3.8

## 更新内容

- 新增按单元退回修改：管理员可选择多个单元并分别说明原因；客户可修改或回复后重新提交。沟通展示双方头像与名称，历史快照仅管理员可见。
- 优化退回项目导航与提示：直接进入可处理的单元，突出退回沟通入口，并区分待客户处理状态。
- 改善客户填写体验：优先上传书籍资料、折叠可选内容、突出校验与保存提示，完善步骤切换及移动端进度展示。
- 后台表单配置改为可搜索、可折叠的分组目录，刷新或切换语言保留分类；修复编辑弹窗溢出，适配手机单列布局，并修正后台页面标题。
- 修复 AI 识别接口地址归一化，兼容已有 Anthropic 配置并明确提示地址错误；保留已有表单内容。
- 加强项目退回、附件访问、并发更新与历史记录相关校验，补充前后端及中英文回归检查。

## Changes

- Request changes for multiple project sections with individual reasons. Customers can revise or reply and resubmit; discussions show participant names and avatars, while historical snapshots remain administrator-only.
- Improve revision navigation, discussion visibility and customer action status.
- Streamline customer forms, optional content, validation feedback, step transitions and mobile progress navigation.
- Replace the long configuration selector with a searchable grouped directory. Preserve category selection across reloads and language changes; fix responsive editing dialogs and admin page titles.
- Normalize recognition endpoint URLs, including existing Anthropic configurations, and clarify endpoint errors without overwriting form data.
- Strengthen revision, attachment access, concurrent-update and history checks, with bilingual regression coverage.

## Upgrade / 升级说明

- 升级前请备份数据库、附件和数据保护密钥。首次启动会自动创建退回记录所需数据表，并补充首次提交时间字段；请保留原数据目录。
- Back up the database, uploaded files and data-protection keys before upgrading. Startup adds revision storage and the first-submission timestamp field automatically. Keep the existing data directory.
- 生产制作流程仍未开放，本次不包含端到端视频生成。/ Production workflow and end-to-end video generation are not included.
