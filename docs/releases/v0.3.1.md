# Lifewood Book Creative Portal v0.3.1

本版本将生产发布收口为一个完整服务端，并补齐 Windows 与 Linux 安装发布链路。

## 主要更新

- `Lifewood.BookPortal.Server` 同一进程提供客户门户、管理中心、账号认证、业务数据与文件。
- 正式发布不再依赖 Node.js、Vite 或独立网页服务器。
- Windows 便携包提供带健康检查的启动器。
- Windows MSI 支持中英文安装界面、端口与数据目录配置，并在覆盖安装时保留生产数据。
- Linux x64 与 arm64 发布包采用统一的 `server/web` 目录，并支持 systemd 安装与配置。
- 客户门户与管理中心根入口根据浏览器或已保存设置选择 `zh-CN`/`en-US`。
- 修复管理后台入口循环重定向和静态资源错误回退为 HTML 的问题。

## 发布资产

- Windows x64 便携 ZIP 与 SHA256。
- Windows x64 `zh-CN`、`en-US` MSI 与 SHA256。
- Linux x64、Linux arm64 压缩包与 SHA256。

AI 生成能力仍不在本版本范围内。
