# Lifewood · Deseret Book v0.3.11

## 更新内容

- 新增运营工作台：按待跟进、等待客户、即将到期、逾期、近期交付及待分配组织项目；支持内部跟进期限、站内到期提醒和资料包导出。
- 新增批量处理：最多 50 个项目，调整负责人、优先级或跟进期限；逐项检查权限和版本，分别返回成功与冲突结果。负责人通过可搜索、分页的用户目录选择。
- 新增趋势报表与 CSV 导出，支持日期、当前组织和负责人筛选；分别统计首次提交、有效交付和当前逾期。逾期按当前仍未完成项目的期限日期统计，不作为历史状态快照。
- 新增账号常用筛选和草稿续填定位；退回资料支持按轮次查看前后差异，保留历史快照和附件对比。
- 新增登录设备管理，可退出指定或全部其他设备，同时撤销旧登录及免密切换凭据；保留当前设备。
- 强化用户管理：在线、离开、离线状态与活动记录，组织成员跳转筛选；支持保留项目及历史的永久账号注销，清除登录与个人资料。
- 新建项目默认采用所属组织名称，未分配组织的账号无法创建项目。
- 优化项目操作布局、设置导航、通知卡片悬停与按需多选、拖动选择、客户背景偏好及中英文界面；修复导航翻译偶发显示键名。
- 修复跨账号私人缓存残留、密码重置后同一浏览器重新登录失败，以及后台常用筛选与浏览器前进/后退不同步。

## Changes

- Add an operations workbench with follow-up queues, deadlines, in-app reminders and project ZIP exports.
- Add version-checked, permission-scoped batch updates for up to 50 projects, with searchable, paginated assignee selection and per-project outcomes.
- Add scoped trend reports and CSV export for first submissions, valid deliveries and currently overdue projects, filtered by date, current organization and assignee. Overdue counts reflect current unfinished projects grouped by deadline, not historical snapshots.
- Add account-owned saved filters, draft resume positions and before/after comparisons of submitted revision rounds.
- Add login-device management and remote sign-out, invalidating both active sessions and quick-switch credentials while keeping the current device signed in.
- Add online/away/offline activity visibility, organization-to-member navigation and permanent account closure that clears credentials and profile information while retaining projects and history.
- Use organization names for new project customer defaults and require organization membership before project creation.
- Refine notification selection/dragging/hover, settings navigation, project actions, customer background preferences and Chinese/English interfaces.
- Fix private cache reuse across accounts, same-browser login after password reset, translation reloads and saved-filter history navigation.

## 升级 / Upgrade

- 升级前备份并保留原数据目录；服务启动时自动迁移数据结构。历史登录仅在匹配有效凭据时升级，失效账号需要重新登录。
- 账号注销不可恢复登录，项目及业务历史继续保留；项目内已有联系人资料不因账号注销被篡改。
- Back up and retain the existing data directory. Startup applies database migrations. Existing login cookies are upgraded only when matching credentials remain valid.
- Account closure permanently removes login access while retaining project and business history, including existing project contact records.
- Windows 提供 ZIP、中英文 MSI；Linux 提供 x64/ARM64 包，各附 SHA-256 校验文件。全部平台构建完成后公开 Release。
- Windows ZIP, Chinese/English MSI, Linux x64 and ARM64 packages include SHA-256 checksums. Release publication waits for all platform builds.
