# Lifewood · Deseret Book v0.3.7

## 更新内容

- 新增模型服务商管理，支持 OpenAI 兼容与 Anthropic 接口格式；服务商维护可用模型，AI 业务独立选择服务商及模型。
- 封面识别结合标题、副标题、简介及 TXT/DOCX 节选判断书籍类型，兼容类型名称匹配；线索不足时留空，不覆盖已有字段。
- 改善手机拍照上传：符合限制的 JPG/PNG 直接上传，减少重复解码；添加处理超时与页面重载后的中断提示。
- 修复 HTTP 局域网上传的 ID 生成兼容性，改善文件错误提示及手机上传文案。
- 修复后台配置页样式加载，精简封面识别区域，补充中英文翻译完整性与动态提示回归检查。

## Changes

- Manage model providers separately from AI features, with OpenAI-compatible and Anthropic protocols and provider-defined model choices.
- Classify books using cover evidence, metadata and TXT/DOCX excerpts. Unknown categories remain blank; existing fields are preserved.
- Improve mobile camera uploads by avoiding unnecessary JPEG/PNG decoding; report processing timeouts and interruptions after page reloads.
- Fix HTTP LAN upload ID compatibility, configuration-page styles and mobile upload wording; expand bilingual regression coverage.

## Known limitations / 已知限制

- Android/Quark camera stability improvements are not a guarantee that all device-specific reloads are resolved. Oversized photos still require browser processing.
- 安卓夸克浏览器的偶发重载仍需更多真机验证；超限照片仍需浏览器处理。
- PDF text extraction is not included. / 暂未接入 PDF 内容提取。

## Release assets / 发布资产

Windows x64 ZIP, zh-CN/en-US MSI installers, Linux x64/arm64 archives, and SHA256 checksums.

Upgrade after backing up your database, uploads and keys. / 升级前请备份数据库、附件和密钥。
