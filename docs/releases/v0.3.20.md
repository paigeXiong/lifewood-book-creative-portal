# Book Creative Portal v0.3.20

## 更新 / Changes

- 新增组织邀请注册：保留管理员创建账号，支持六位字母邀请码、有效期、人数限制、停用和使用记录，以及复制邀请链接。
- 客户注册共用登录页布局，填写昵称、邮箱和邀请码后验证邮箱，设置密码并注册；支持失败恢复，成功后预填登录邮箱。
- 账号切换区分记住的身份与登录会话，过期后提示重新登录；普通退出只退出当前账号，清除全部账号需单独确认。
- 定时任务增加标题搜索、状态筛选、分页和关联公告跳转；公告支持发布前的展示效果预览。
- 邮件记录支持收件邮箱或域名检索；统一审计、反馈工具栏与侧边分类样式，精简客户组织卡片。
- 项目卖点、简介增加字数反馈；补齐中英文邀请注册教程和管理员排查说明，客户文档 14 篇、管理文档 19 篇。

- Add organization-bound invitation registration alongside administrator-created accounts, with six-letter codes, expiry, capacity, revocation, registration history and shareable links.
- Integrate registration into the sign-in layout, verify email before account creation, support recovery and prefill the sign-in email after registration.
- Separate remembered identities from active sessions. Expired accounts request authentication; normal sign-out affects only the current account, with a separate confirmed clear-all action.
- Add scheduled-task search, state filters, pagination and linked-announcement navigation, plus announcement placement previews.
- Search mail records by recipient or domain, unify administration toolbars and sidebar groups, and simplify customer organization cards.
- Add character counts and bilingual onboarding/troubleshooting help: 14 customer and 19 administration articles.

## 升级说明 / Upgrade notes

- 升级前备份数据目录，保留数据库、附件、配置和数据保护密钥。启动时自动创建邀请码及记住账号的数据表。
- 邀请码仍须通过邮箱验证，注册邮件沿用队列和发送限额；邀请链接使用已配置的客户门户地址，正式使用前确认 HTTPS 域名。
- 旧的长邀请码仍有效。未保存或已丢失的浏览器账号记录无法自动恢复；清理 Cookie 后需重新添加。记住账号不会延长登录权限。
- 此版本不更改项目业务流程或现有账号的组织、角色，不自动启用邮件通知。

- Back up the data directory and preserve the database, attachments, configuration and data-protection keys. New invitation and remembered-account tables are created on startup.
- Invitations require email verification and use the existing mail queue and quotas. Shared links use the configured customer portal URL; confirm the production HTTPS domain before use.
- Existing long codes remain valid. Previously lost account entries cannot be recovered automatically; clearing cookies requires adding accounts again. Remembering identities does not extend authentication.
- This release does not change project workflows, existing account organizations/roles or enable email subscriptions automatically.
