# Lifewood · Deseret Book v0.3.10

## 更新内容

- 新增客户与后台站内通知中心：覆盖项目提交、重交、退回、回复、进度、交付和账号变更，支持筛选、批量已读、归档恢复、关联事项跳转、声音与免打扰偏好。
- 增加通知模板、接收规则、发送记录、失败重试与保留期限；强化已读/未读区分，优化通知弹窗的固定高度、滚动和无背景图标操作。
- 公告以公示天数替代开始、结束时间，超过期限不再自动弹出；支持单份标题正文、发布前收件人数预览、筛选和草稿删除，简化关闭操作。
- 新增快捷切换账号：首次验证后，在登录有效期内可切换最多 5 个账号。支持添加与移除，跨页面账号变化时暂停旧页面操作，退出登录清除本设备快捷登录。
- 新增运营人员角色，细分查看、跟进、分配、退回、回复、备注与交付权限。运营仅可处理分配给自己的项目；管理员保留项目分配、账号和业务配置管理，平台负责人保留系统运行控制。
- 客户可删除自己的已退回项目，删除校验覆盖归属、版本与项目状态，并清理对应退回记录、通知和文件。
- 项目列表改为回车搜索，压缩工具栏为桌面单行，新增待处理统计卡片；同步桌面、窄屏及中英文界面。
- 修复通知断线刷新、偏好加载失败后的保存保护、大批量通知重试计数及账号切换后的请求隔离；发布包显式排除本地运行数据。

## Changes

- Add customer and administrator notification centers for submissions, revisions, replies, progress, deliveries and account changes, with filters, bulk read actions, archive/restore, related-item navigation, sound and quiet hours.
- Add notification templates, recipient rules, delivery logs, retries and retention. Improve read/unread distinction, fixed-height dialogs, scrolling and background-free icon actions.
- Replace announcement date inputs with a display duration in days; expired announcements stop opening automatically. Add single title/body editing, recipient previews, filters and draft deletion, and simplify dismissal.
- Add quick switching between up to five verified accounts while their sessions remain valid. Support adding/removing accounts, pause stale pages after cross-tab account changes, and clear device quick access on sign-out.
- Add an operations role with assigned-project-only access. Separate project reading, workflow updates, assignment, returns, replies, notes and delivery permissions; administrators retain account/configuration management and owners retain runtime controls.
- Allow customers to delete their own returned projects, with ownership, version and state checks and cleanup of associated revision records, notifications and files.
- Add Enter-to-search, a compact desktop toolbar and an action-needed summary card. Update desktop, narrow-screen, Chinese and English interfaces.
- Fix notification refresh during stream interruptions, preference save recovery, bulk notification retry counts and account-bound requests. Explicitly exclude runtime data from release packages.

## 升级 / Upgrade

- 升级前备份并保留原数据目录。启动时自动更新所需表与触发器，不补发升级前通知；旧公告内容、期限及关闭记录保留。已有客户、管理员和平台负责人角色保持原有职责，运营角色由后台账号管理设置。
- Back up and retain the existing data directory. Startup updates storage and triggers without replaying historical notifications, and preserves legacy announcement content, expiry and dismissal. Existing roles keep their responsibilities; administrators can assign the new operations role in account management.
- Windows 提供便携 ZIP 和中英文 MSI；Linux 提供 x64 与 ARM64 安装包，均附 SHA-256 校验文件。
- Windows assets include a portable ZIP and Chinese/English MSI installers; Linux packages cover x64 and ARM64. SHA-256 checksums accompany each package.
