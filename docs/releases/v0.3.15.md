# Book Creative Portal v0.3.15

## 今日更新 / 2026-09-15

- 改善客户大文件下载：支持浏览器能力允许时流式保存，补齐取消、失败重试、账号变化校验和存储配额提示。
- 完善草稿冲突处理与通知跳转恢复，保留未保存输入，避免迟到响应作用到其他账号或页面。
- 改善后台音色上传、备份与资料导出：失败后可继续处理，支持取消，避免重复操作及旧请求覆盖新结果。
- 补齐备份策略、项目截止日期等弹窗的未保存确认，处理返回导航、重复确认和保存中的关闭竞争。
- 公告编辑支持当前标签页草稿恢复、组织选择往返、版本冲突保留与明确确认后另建草稿；保留旧公告双语内容。
- 公告发布、下架、删除统一处理确认、请求和刷新，区分版本冲突、记录不存在及结果未确认；不会自动重发。
- 公告列表保留搜索、筛选和加载页数，支持历史前进/后退及刷新恢复，修复分页与导航竞争。新增交互均适配中文和英文。
- 完成并记录 500 MB 传输、中断恢复、持续读写、附件增长和配额竞争测试；补充 GC/内存诊断与剩余需求说明。

## Changes

- Improve large-file downloads with capability-based streaming saves, cancellation, retry, account guards and storage-quota feedback.
- Preserve edits during draft conflict recovery and improve notification navigation when accounts or pages change.
- Harden admin voice uploads, backup downloads and exports against cancellation, failed requests and duplicate actions.
- Extend unsaved-change protection to backup policies and project deadlines, including navigation and confirmation races.
- Retain announcement drafts across organization selection and reloads. Preserve conflicting edits and offer explicitly confirmed new drafts without overwriting the original; retain legacy bilingual content.
- Coordinate announcement publication, withdrawal and deletion through confirmation, request and list refresh. Distinguish conflicts, missing records and uncertain outcomes without automatic replay.
- Restore announcement filters and loaded pages through browser history, with bounded cursor recovery and stale-response protection. New interactions support Chinese and English.
- Document 500 MB transfers, interrupted requests, sustained workloads, attachment growth, quota contention and memory diagnostics.

## 验证与边界 / Validation and limits

- 本地客户 356 项、后台 156 项、服务端 321 项测试通过，共 833 项；两套前端生产构建通过。发布流水线还会构建并验证 Windows ZIP、中英文 MSI、Linux x64/ARM64 安装包和 SHA-256 文件，全部成功后公开。
- Local validation passed 356 customer, 156 admin and 321 API tests (833 total), plus both frontend production builds. The release pipeline publishes only after Windows ZIP, localized MSI, Linux x64/ARM64 packages and checksums are built and checked.
- 压测和大文件结果限于文档中的隔离测试条件，不代表生产最大容量、所有浏览器或目标服务器已经验收。
- Load and transfer results apply to the documented isolated test environments; they do not certify production capacity, every browser or the target server.
- 本版不新增真实制作工作流、平均交付耗时、外部邮件/短信渠道或分片直传，相关业务与部署决策仍待确认。
- Real production workflow, delivery-duration metrics, external email/SMS and chunked direct uploads are outside this release.

## 升级说明 / Upgrade notes

升级前备份数据库、上传文件、成品与数据保护密钥；通过既有安装/升级流程更新。配额错误可重试标记的服务端修正需要运行新版服务后生效。公告暂存只限当前标签页，不能代替服务端保存或跨设备同步。

Back up the database, uploads, deliverables and data-protection keys before using the existing upgrade procedure. The server-side retryable quota response requires the updated service. Announcement recovery is tab-scoped and does not replace server saves or cross-device synchronization.
