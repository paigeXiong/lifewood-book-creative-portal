# Book Creative Portal v0.3.18

## 更新 / Changes

- 同组织成员共享项目查看权限，仅创建人可修改；项目列表展示创建人并支持进入成员资料，返回时保留来源。
- 客户数据概览支持个人与组织统计口径切换，相关指标、活动和项目入口保持一致。
- 新增中英文帮助中心，包含搜索、常见问题、操作指南和演示截图；未登录用户可阅读客户文档，管理文档保留权限检查。
- 后台顶部增加功能与帮助搜索；系统配置按内容、接入、通知、运维分组，调整侧栏和导航布局。
- 邮件模板改为独立编辑页面，支持中英文主题与正文、恢复默认、预览和模板测试；业务通知可按语言启停，必要安全邮件始终启用。
- 统一分段切换控件，修复导航动画、输入聚焦、反馈附件选择及帮助文档切换体验。

- Share project visibility within an organization while restricting edits to the creator, with creator profile links and contextual return navigation.
- Switch customer dashboard metrics between personal and organization scopes.
- Add a bilingual searchable help center with FAQs, tutorials and demonstration screenshots; customer guides are public and administrator guides remain access-controlled.
- Add administrator feature search, grouped settings navigation and a refined sidebar.
- Provide a dedicated bilingual email template editor with restore, preview and test actions; business notification templates may be disabled per language while essential security messages stay enabled.
- Unify segmented controls and improve navigation, focus, feedback attachments and help transitions.

## 使用与升级 / Usage and upgrade

- 邮件模板入口：系统配置 → 消息通知 → 邮件服务 → 邮件模板。修改内容应用于新入队邮件；停用通知模板会阻止尚未发送的对应语言通知，停用期间的通知不会补发。
- 模板测试需手动触发，发送到配置的发件邮箱，使用无效示例链接。不会执行邮箱验证或密码重置。
- 升级前请备份数据目录，保留现有数据库、上传文件和本地配置。正式域名、生产邮件服务及真实制作工作流仍需部署配置和业务验收。

- Open Settings → Messaging → Mail service → Email templates. Edits apply to newly queued messages; disabling a notice template also blocks unsent messages in that language, and notices skipped while disabled are not replayed.
- Template tests are manually triggered, addressed to the configured sender mailbox and contain inactive example links.
- Back up the data directory before upgrading and retain the database, uploads and local configuration. Production domains, mail delivery and the real production workflow still require deployment configuration and business acceptance.
