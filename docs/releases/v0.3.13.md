# Lifewood Book Creative Portal v0.3.13

## 更新内容

- 新增客户右上角“问题反馈”入口与后台“平台反馈”管理，支持问题描述、截图、搜索、状态筛选和分页。管理员回复通过现有站内通知送达，通知详情同时展示原问题和回复。
- 反馈截图支持选择 10 MB 以内的 PNG、JPEG、WebP 原图，在上传前自动压缩。优先无损处理、保留文字清晰度，小图不重复压缩；修复取消选图导致反馈弹窗关闭的问题。
- 完善文件上传进度、取消和重试；通过稳定上传标识处理回执丢失，避免重复附件，并保护上传期间的文本修改。
- 增加草稿版本冲突的逐字段对比和恢复；提交结果不明确时先核对服务器状态，避免重复提交或误报成功。
- 优化手机表单布局、键盘操作与错误定位。调整个人资料面板、项目导航、图标动效、筛选按钮、默认封面及空状态；统一表格字号、排序图标和更多操作入口。
- 调整组织品牌图片的列表展示，修复后台审计表格透明行与页面底色混合的问题。
- 增加备份异常的负责人通知、持久化状态校验和页面按需加载，并补充相关稳定性验证。
- 同步适配中英文，补充反馈权限隔离、通知唯一性、恶意输入、断网恢复及真实大图的回归验证。

## Changes

- Add customer platform feedback and an admin collection page with screenshots, search, status filters and pagination. Admin responses arrive in the existing notification center with the original report; no separate chat interface is introduced.
- Accept feedback screenshots up to 10 MB and compress them before upload, preferring lossless encoding and readable text. Preserve fitting originals and prevent file-picker cancellation from closing the feedback dialog.
- Improve upload progress, cancellation and retry. Stable upload identifiers prevent duplicate attachments after lost responses while retaining text edits made during uploads.
- Add field-by-field draft conflict recovery and verify server state before retrying uncertain project submissions.
- Improve mobile forms, keyboard focus and validation navigation. Refine profile panels, navigation, icon motion, filtering, default covers, empty states, typography, sort icons and row actions.
- Refine organization wordmarks and give the audit table a distinct white surface with subtle alternating rows.
- Include owner notifications for backup failures, persistent backup-state checks, lazy-loaded portal pages and related stability fixes.
- Extend Chinese and English coverage and regression checks for feedback authorization, notification uniqueness, untrusted input, network recovery and large screenshots.

## 范围与升级 / Scope and upgrade

- 保持原有项目与历史记录，启动时自动创建反馈相关数据表。反馈与截图随平台数据库备份保存。
- Existing projects and history are preserved. Feedback tables are created on startup, and feedback/screenshots are included in database backups.
- 本版不包含邮件通知、短信或新的视频生产工作流。/ Email, SMS and new video-production workflows are not included.
- Windows ZIP、中英文 MSI、Linux x64/ARM64 发布包均附 SHA-256 校验文件，构建与校验完成后公开。/ Windows ZIP, bilingual MSI and Linux x64/ARM64 archives include SHA-256 checksums and are published after package verification.
