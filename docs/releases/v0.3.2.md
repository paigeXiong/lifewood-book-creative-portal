# Lifewood Book Creative Portal v0.3.2

本版本修复生产发行包首次启动时无法注册平台负责人的问题，并完善安装配置校验。

## 主要更新

- Windows 与 Linux 发行版不再依赖开发环境或 `AllowInsecureHttp` 兼容开关。
- 服务端直接启动后可通过本机 `http://localhost:5000` 完成首次注册、登录并访问客户门户与管理中心。
- 非本机 Production HTTP 请求仍会被拒绝；反向代理部署必须配置可信代理并使用 HTTPS。
- 加固代理来源判断，阻止伪造转发头及可信回环代理的明文降级。
- Windows MSI 改进端口输入和生产数据目录必填校验，中英文安装界面保持一致。
- 覆盖安装继续保留原有生产数据库和上传文件。

## 验证

- 服务端自动化测试 53 项通过。
- Windows Native AOT Production 注册与登录冒烟测试通过。
- Windows 便携包同时包含服务端、客户门户和管理中心。
- 中英文 MSI 构建及覆盖安装数据保留检查通过。

## 发布资产

- Windows x64 自包含便携 ZIP 与 SHA256。
- Windows x64 中文 MSI 与 SHA256。
- Windows x64 English MSI 与 SHA256。
- Linux x64 自包含压缩包与 SHA256。
