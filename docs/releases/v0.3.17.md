# Book Creative Portal v0.3.17

## 更新 / Changes

- 完善后台邮件服务配置、状态诊断、中英文邮件模板和预览；个人邮件通知可分别选择完成、退回、交付、回复及其他事件。
- 增加全局出站代理及业务覆盖配置，支持邮件、OIDC 与 AI 接入按配置连接。
- 客户可查看我的组织、成员资料、提交统计及登录活跃月历；后台组织成员支持添加、创建和管理入口。
- 管理端增加效率统计、样本量及趋势联动；改善客户概览交互、刷新和弹窗动效、分页位置与小屏布局。
- 项目列表支持复制本人项目为独立新草稿，清除附件、期限和流程记录，校验草稿上限并防止重复请求创建。
- 现有运行监控增加数据库、头像和其他文件分类，独立计量备份目录；修复永久注销遗漏的活跃日历清理。
- 更新双语 README、真实应用截图和验收会议清单。新增界面支持中文和英文。

- Expand owner-managed mail configuration, diagnostics, bilingual templates and previews, with selectable notification categories.
- Add global outbound proxy configuration and per-service overrides for mail, OIDC and AI integrations.
- Add customer organization/member profiles, submitted-request summaries and activity calendars; improve admin member management.
- Add admin efficiency metrics with sample counts and drill-downs; refine dashboard interaction, refresh/modal motion, pagination and mobile layouts.
- Copy owned projects into independent drafts with attachment/workflow resets, draft limits and idempotent retries.
- Break down runtime storage and separately measure managed backups; remove activity-calendar data during permanent account closure.
- Refresh bilingual documentation, application screenshots and the acceptance-meeting checklist.

## 验证与边界 / Validation and scope

发布前通过客户 616 项、管理端 257 项、服务端 475 项测试，共 1,348 项；运维回归及两端生产构建通过。Windows Native AOT ZIP、中英文 MSI、Linux x64/ARM64 安装包及校验文件由发布流水线构建验证，全部成功后公开。

Pre-release checks passed 616 customer, 257 admin and 475 API tests (1,348 total), operations regressions and both production frontend builds. The release workflow validates Windows Native AOT ZIP, localized MSI and Linux x64/ARM64 packages with checksums before publishing.

本地 QQ SMTP 的中英文模板实收已确认；正式门户域名下的验证/找回密码链接、真实 OIDC 服务、目标服务器恢复和业务会议验收仍待完成。本版没有新增成品下载中心，也没有扩展正式制作工作流。管理端完成耗时按首次提交到完成的总历时统计，包含等待时间，显示样本量。

Local QQ SMTP template delivery has been confirmed in both languages. Production-domain email links, real OIDC providers, target-server recovery and business acceptance remain pending. This release adds no separate download-center page or production workflow. Admin completion metrics use elapsed time from first submission to completion, including waiting, with sample counts.

## 升级 / Upgrade

升级前备份数据库、附件、成品和数据保护密钥。使用现有安装/升级流程，启动时自动更新数据结构。保留密钥以解密邮件及代理配置；真实凭据不随发布包分发。既有用户不会被自动订阅邮件，已开启邮件的用户保留原有全部类型。

Back up the database, attachments, deliverables and data-protection keys. Use the existing upgrade procedure; schema updates run on startup. Preserve encryption keys for mail/proxy configuration. No real credentials are distributed. Existing users are not automatically subscribed; existing subscriptions retain all categories.
