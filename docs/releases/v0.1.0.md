# v0.1.0 — 首个可用版本

发布日期：2026-08-25

## 版本定位

这是 Lifewood Book Creative Portal 的首个可部署版本，覆盖客户提交书籍影像项目资料、内部管理员跟进、账号管理和最终成品交付的完整基础流程。平台不包含 AI 生成能力。

## 主要功能

### 客户门户

- 真实账号登录与安全 Cookie 会话。
- 中文、英文独立路由及完整界面国际化。
- 创建项目草稿，填写项目、书籍、角色、创意方向、音色与参考资料。
- 上传书籍封面、原稿和参考文件。
- 服务端校验、幂等提交和提交后资料冻结。
- 查看受理进度、最终成品并下载交付文件。
- 使用真实图片形式的首字母头像。
- 用户可自行修改密码，修改后旧会话立即失效。

### 管理中心

- 管理员入口、真实权限校验和紧凑型项目跟进界面。
- 跨客户搜索、筛选、分页和项目详情查看。
- 修改跟进状态、优先级、负责人和内部备注。
- 创建、启用和停用客户或管理员账号。
- 重置非所有者账号密码，并立即撤销目标用户旧会话。
- 从任意制作阶段快捷上传最终成品。
- 撤回最终成品；撤回最后一个成品后项目恢复为制作中。

### 部署与运维

- C# / .NET 10 ASP.NET Core Minimal API。
- SQLite 持久化与渐进式架构迁移。
- Windows x64 Native AOT 发布。
- 同域部署支持：客户门户位于根路径，管理中心位于 /admin/，API 位于 /api/。
- Windows BAT 本地启动与停止脚本。
- 带平台互斥锁的数据备份脚本，避免运行中生成不一致备份。
- 客户门户、管理中心与 API 健康检查。

## 质量验证

- 客户前端：18 项自动测试通过。
- 管理端：6 项自动测试通过。
- 后端：3 项临时 SQLite 集成测试通过。
- Native AOT 发布与实际启动验证通过。
- 独立代码审查未发现 Critical 或 Important 问题。

## 发布包

Windows x64 发布包包含：

- customer/：客户门户静态文件；
- admin/：管理中心静态文件；
- api/：Native AOT 平台 API；
- DEPLOYMENT.md：部署结构与数据目录说明。

首次部署前请阅读 docs/deployment-and-backup.md。正式环境必须使用 HTTPS，并妥善保护 api/data/。

## English summary

The first deployable release of Lifewood Book Creative Portal includes the bilingual customer intake portal, formal admin center, real account authentication, project workflow tracking, user administration, final delivery upload/withdrawal, SQLite persistence, Windows x64 Native AOT API, and safe local backup tooling. AI generation features are intentionally out of scope.
