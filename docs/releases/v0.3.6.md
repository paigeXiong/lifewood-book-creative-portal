# Lifewood · Deseret Book v0.3.6

本版本改进图书视频需求采集流程、登录展示和管理后台布局，并完善本地启动与备份恢复。

## 更新内容

- 登录页采用双栏面板，加入循环展示、滚轮翻页及书本网格动效。
- 六步表单加入方向切换动画；自动保存保持静默，离开步骤前等待最新修改保存完成。
- 固定选项统一为单行可滑动选择，整理书籍信息、品牌线、视频目标和目标受众的布局。
- 完善角色预设、视觉风格预览、配音配置和图书识别流程。
- 项目列表整合悬浮筛选，增加统计图标，改进详情页信息层次。
- 用户管理、组织管理的分页栏保持在列表面板底部，列表内容独立滚动。
- 修复故事角色页声音提示输入框与参考图上传区的聚焦边框重叠。
- 完善服务启动入口、备份恢复锁及数据完整性检查，补充 Linux 首次管理员初始化说明。
- 保持简体中文、英文界面兼容，并支持减少动态效果偏好。

## Release contents / 发布资产

- Windows x64 portable ZIP and SHA256 / 便携压缩包与校验文件。
- Windows x64 zh-CN and en-US MSI installers and SHA256 / 中英文安装包与校验文件。
- Linux x64 and arm64 archives and SHA256 / 两种架构的压缩包与校验文件。
