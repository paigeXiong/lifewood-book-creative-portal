# Lifewood Book Creative Portal v0.3.3

本版本集中完善客户门户与管理后台的界面稳定性、错误恢复能力和需求文档，为后续真实业务流程开发提供更可靠的基础。

## 主要更新

- 优化管理后台项目跟进双栏布局，收紧列表宽度、内容密度和滚动行为，避免项目列表被拉伸或详情区域跳动。
- 完善移动端与键盘操作细节，修正跳转主内容、当前项目状态和图片尺寸等无障碍语义。
- 客户门户、管理后台和可移除测试控制台加入统一的页面崩溃兜底，不再因单个组件异常直接白屏。
- 断网、无效 JSON、空白错误体和不完整错误对象统一转换为安全、可本地化、可重试的错误提示。
- 项目填写、角色配置、配音参考、提交复核、项目详情和提交结果页面均提供失败重试入口。
- 管理后台无法连接服务端时显示明确错误，不再误导用户进入普通登录流程。
- 原始运行时异常不再直接展示给用户，保留服务端请求编号、字段错误和版本冲突信息。
- 重新梳理产品范围、需求来源与当前登记平台边界，明确 AI 生成能力仍不在当前版本范围内。
- 所有新增用户界面与错误文案均提供 `zh-CN` 和 `en-US` 版本。

## 验证

- 客户前端 44 项自动化测试通过。
- 管理后台 25 项自动化测试通过。
- 服务端 53 项自动化测试及备份特殊文件名验证通过。
- 客户门户、管理后台和可移除测试控制台生产构建通过。
- GitHub 发布流水继续执行服务端测试、Windows Native AOT 冒烟、便携包、双语 MSI 以及 Linux x64/ARM64 自包含包验证。
