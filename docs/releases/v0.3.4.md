# Lifewood Book Creative Portal v0.3.4

本版本集中完善客户个人资料、项目登记体验、管理员项目跟进和平台运行配置，使当前展示版本更接近可直接部署和演示的完整产品。

## 主要更新

- 新增完整的个人资料页面，支持头像、姓名和联系电话维护，并将最新资料自动带入新建项目草稿。
- 客户项目列表加入可切换字段与方向的排序、居中页码分页、真实封面与统一缺省封面。
- 优化项目登记表单的信息图标、步骤进度、可编辑选项和移动端交互密度。
- 管理后台改为紧凑浅色分组导航，收紧超宽屏内容比例，增强概览卡片和详情键值的视觉层级。
- 项目跟进切换使用单一 URL 状态源并保留旧详情至新数据就绪，消除详情文字闪烁。
- 故事角色改为名称标签切换，一次聚焦一个角色详情，并支持方向键、Home 和 End 键。
- 新增管理员运行配置入口，可查看和调整监听地址、端口，并按权限执行平台重启或关闭。
- 用户与组织、项目表单和服务端资料模型完成联动；密码最小长度统一为 8 个字符。
- Windows 启动脚本支持监听所有网络接口，并明确远程访问必须经过可信 HTTPS 反向代理。
- 所有新增界面、提示和错误信息继续提供简体中文与英文版本。
