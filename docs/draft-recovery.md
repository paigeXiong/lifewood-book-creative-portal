# 草稿编辑冲突恢复

当保存或上传遇到版本冲突时，客户表单提供“比较最新版本”。读取失败、取消比较或关闭弹窗都不会替换当前输入。

## 处理方式

- 对比本次输入和服务器最新内容，只列出不同的可编辑字段。默认采用服务器版本，用户可逐字段选择保留本次输入。
- 书籍资料、角色与风格、配音与创意方向共用此交互，支持中文和英文。枚举展示服务端名称，停用且无可用名称的选项显示不可用提示，不显示内部 ID。
- “应用并继续编辑”再次读取服务器并校验版本及本地快照。若内容又变了，刷新比较、清空选择，等待重新确认。
- 应用后使用最新服务器版本作为保存基线，只恢复明确选中的字段，沿用表单校验和自动保存；后续写入仍由服务端版本检查保护。
- 恢复内容尚未保存时，前置步骤不完整不会立即跳走；保存成功后再返回需要补充的前置步骤。失败或校验不通过时保留输入，用户仍可处理。

## 数据边界

附件、预设图片地址和内部标识始终采用服务器记录。角色按 ID 匹配，已有角色支持逐字段恢复；新增或已删除的未匹配角色不自动重建，原输入可以复制。配音步骤只比较其保存接口实际接收的字段，项目基础资料在参考创意步骤处理。

项目已不可编辑时不能恢复写入，可先复制本次输入再载入最新状态。对比数据只保存在当前页面内存中，不写入浏览器长期存储；“复制本次输入”仅在用户主动点击时写入剪贴板。

## 验证

- 客户前端：文本安全渲染、两种语言、字段白名单、角色重排、读取期间继续输入、二次冲突、切换项目、选择应用及前置步骤变化的回归。
- 浏览器：桌面中文与手机英文，使用真实服务器制造两次版本冲突，验证所选本地字段和未选择的最新字段同时保存。
