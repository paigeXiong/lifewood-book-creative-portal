# 2026-09-15 工作记录

Book Creative Portal 是面向客户的书籍视频创意资料登记与协作平台，由 Lifewood 团队建设。当前包含资料提交、人工跟进、定向退回、最终成品交付及管理后台；Lifewood 是公司名称。

## 今日完成

1. 客户体验：大文件流式下载与取消/重试，草稿冲突和通知跳转恢复，存储配额错误提示。
2. 后台稳定性：音色上传、备份和资料导出的取消/失败恢复；备份策略及截止日期等表单的未保存保护。
3. 公告管理：跨页草稿保留、组织选择恢复、版本冲突另建草稿、双语内容保留，发布/下架/删除的确认锁与失败刷新，筛选及加载范围的历史恢复。
4. 验证与文档：500 MB 大文件及中断测试、持续读写、附件增长、配额竞争、GC/内存观测，更新需求边界和待确认事项。
5. 发布准备：版本统一至 v0.3.15；本地客户 356 项、后台 156 项、服务端 321 项测试通过，共 833 项；两套前端生产构建通过。发布包由 GitHub Actions 构建并校验后公开。

## 仍待推进或确认

- 真实制作工作流：制作节点、负责人、审片、返修和多版本交付规则。
- 组织共享权限、成员邀请、多组织及客户主动变更规则。
- 正式授权材料、必填文件类别、角色/配音等需求图片中的业务细节。
- 生产域名、HTTPS、代理与存储配额、备份及恢复目标，目标服务器和真机浏览器验收。
- 是否启用邮件等外部通知，以及对象存储、分片上传等大文件架构。

今日压测结论仅适用于文档中的隔离环境，不等于生产容量或所有终端验收。未新增平均交付耗时统计。现有预览进程保留，服务端更新在正常升级/重启后生效。
