# 持续新增附件与文件清理验证

日期：2026-09-15。接续[持续读写与空闲观察](./sustained-load-validation.md)，新增 `--file-growth` 专项，验证真实新增文件、类别数量上限、删除和补传。它使用独立端口 5097 及 `artifacts/api-benchmark/<UUID>`，不操作客户正在查看的开发服务或业务数据。

## 场景与边界

- 一万条较重合成背景记录，两个客户各有中英文两个有效项目；四个读取流程与四个写入流程并行。
- 每个项目先上传一张封面，再每五次持续保存（间隔约 30 秒）新增一张约 1 MiB 的有效 PNG。每张补充图片使用不同字节、上传 ID 和文件名；相关请求携带对应的 `Accept-Language`。
- 保持默认 `supplemental-images` 类别最多 8 张的配置。每次新上传后，以同 ID、相同内容和旧版本重放，验证只保留一个附件且版本不重复递增；满额时最后一次重放也必须成功。
- 满 8 张后尝试第 9 张，要求 `400` 和 `too_many`，同一 GET 接口的完整前后响应一致。此时核对全部保留文件的数量、逻辑大小和 SHA-256，确保被拒绝的请求未破坏已有文件。
- 每个项目删除两张尚未提交的补充图片，确认版本递增、元数据移除、原 URL 返回 404、对应磁盘文件消失；随后上传两张不同内容的图片并重放，验证释放的名额可重新使用。
- 最终每项目保留 1 张封面和 8 张补充图片，共 36 个文件；整个过程成功创建 44 个文件并删除 8 个。提交和服务重启前后，逐项比较附件 ID、类别、名称、类型、大小及 URL，并核对本地文件与 HTTP 下载哈希。磁盘文件数量须与预期清单完全一致。

文件快照按项目范围在每次上传/重放、拒绝、删除及最终持久性检查后记录。不同项目同时变化，因此不能把这些不同时间的快照简单相加当作同一时刻的全盘快照。字节数是逻辑文件大小，不是文件系统实际分配量、磁盘剩余容量或 I/O 吞吐量。资源采样及空闲阶段口径沿用持续验证说明。

本测试只在已有项目中增加小图片；没有持续创建无限项目、填满磁盘、修改存储配额或注入断电。配置存储配额不足（507）已另行完成[专项验证](./storage-quota-validation.md)；真实磁盘写满、生产代理、大文件并发和历史修订文件的保留策略属于其他场景。类别数量上限拒绝不能称为存储容量上限拒绝。

## 复现

先按持续测试文档构建独立 Release DLL。新增模式要求 `--sustained` 且时长不少于 240 秒，确保能按节奏达到 8 张上限，不通过突发补传或放宽平台限流凑满数量。

```powershell
node scripts/benchmark-api.mjs artifacts/sustained-20260915-dotnet/bin/Lifewood.PlatformApi/release/Lifewood.BookPortal.Server.dll --sustained --seconds=240 --idle-seconds=30 --file-growth
node --test scripts/benchmark-file-growth.test.mjs
```

报告的 `fileGrowth` 保存各项目的保留清单、已删除 ID、新图片哈希和阶段文件快照；总验收仍以 `mixed.passed`、资源报告及命令退出码共同判断。校验器另有三项回归：有效清单通过、相同数量的错误 URL 被拒绝、同大小但不同内容的文件在上限拒绝检查时被发现。

## 本机结果

Windows 11、Node v24.16.0，沿用持续验证的托管 Release DLL（SHA-256 `c26cbe2ab773f4dacdc1edcb966d762e76f85f710668fc899828f9898538dbe1`）。实际负载 241.09 秒，随后同进程空闲 30.02 秒；命令退出码 0，业务、文件增长和资源报告均通过。

- 负载阶段记录 8,803 次业务操作，含准备与后续验证共 8,829 条计时记录；不包括 CSRF、附件哈希下载等辅助调用。非预期失败 0，429 为 0。
- 四项目各完成 48 次保存、10 张不同内容的补充图片上传及 10 次重放。另有初始封面上传各 1 次、封面重放各 5 次。
- 四次超出类别数量上限均按预期返回 `400 / too_many`；拒绝后的完整 GET 快照和全部现存文件哈希不变。两个 409、两个 404 的原有冲突及隔离检查也通过。
- 成功创建文件共 44 个，删除 8 个，最终保留 36 个，逻辑文件总大小 37,781,136 字节。提交后及重启后的项目数据、逐项附件信息、本地与 HTTP 文件哈希一致，未发现额外、暂存或孤立文件。

舍弃阶段边界附近样本后，负载使用 237 个资源样本、空闲使用 28 个。负载私有内存均值 / 峰值为 65.88 / 90.18 MiB，空闲首 / 末为 69.52 / 67.26 MiB；本轮空闲未回到起始水平，不能凭短程数据证明不存在泄漏。资源数据仅属于隔离服务进程，不包含生成图片和分析数据的 Node 进程。
