# 2026-09-11 稳定性与体验增强

## 实现

- 备份归档完成后，等待审计及临时目录收尾，再在同一锁内发布终态并释放任务占用。终态写盘失败不会伪报完成或在内存中停留在执行状态。
- 备份异常接入站内通知：自动失败、已确认损坏、两个计划周期无成功备份；负责人专属、持久化去重、解除状态与双语跳转。
- 后台项目、用户及通知设置页面按需加载；客户修改工作区仅在具体任务中加载。基础库单独缓存，保留同步双语资源初始化。
- 审计、备份、恢复记录、角色排序及常用筛选中的遗漏图标按钮复用已有点击反馈，保留禁用和减少动态效果规则。

## 体积口径

`node scripts/report-web-bundles.mjs` 读取 Vite manifest，递归累加入口的静态 JavaScript 依赖；不把 vendor 分离误算为传输减少。优化前客户入口约 546.21 KB、后台 670.28 KB；优化后初始静态请求合计约 540.53 KB、588.12 KB。页面按需块在访问相应路由时另行加载，数值不代表实际网络耗时。
