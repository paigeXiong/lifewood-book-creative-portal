# 当前产品需求基线

本文档定义当前可开发、可验收和可交付的产品范围。平台面向书籍视频制作客户，负责收集需求、保存资料、提交项目，并支持内部人员人工跟进和交付最终成品。发生范围冲突时，以本基线及之后用户明确批准的变更为准；原型、评估建议和待确认批注不会自动扩大开发范围。

## 文档边界

本基线用于统一产品、设计、前端、服务端、测试和部署判断：

| 项目 | 约定 |
| --- | --- |
| 产品 | Book Creative Portal（仓库及发布名称：Lifewood Book Creative Portal） |
| 开发公司 | Lifewood |
| 业务领域 | 书籍到视频制作需求 |
| 当前阶段 | 客户需求登记、人工跟进与最终成品交付 |
| 目标用户 | 客户、运营、管理员、平台负责人 |
| 支持语言 | `zh-CN`、`en-US` |
| 数据来源 | 平台真实服务端、SQLite 和平台文件存储 |
| 详细资料 | [客户字段与流程](./product-requirements.md)、[管理中心](./admin-center-requirements.md)、[UI 规范](./ui-design-specification.md) |

需求原图描述了完整生产设想，也包含 AI 参考页面。当前阶段不实现完整制作工作流；已批准的 AI 能力限于书籍资料辅助识别与其接入配置。

## 维护范围确认（2026-09-07）

继续维护客户需求登记、人工跟进与最终成品交付；优先修复已有流程的问题，改善保存、上传、步骤切换、定向退回和交付反馈。所有客户与管理端改动必须同时适配中文、英文及移动端。

以下增强已由用户明确批准，覆盖早期“无 AI”“提交后完全不可修改”“无站内沟通”的绝对限制：

- 封面识别辅助录入，以及模型服务商、协议、可用模型和 AI 业务绑定配置。
- 管理员按资料单元定向退回、双方沟通、客户重新提交及管理员查看退回历史。
- 头像统一从个人页面修改。
- 平台公告、按天配置公示期，以及业务事件驱动的站内通知；详见本文末尾的已批准补充。

新增审批节点、账号共享、交付版本或通知渠道均须先确认业务规则。快捷账号切换、批量处理及资料导出已实现，见[账号切换](./account-switching.md)、[效率工具](./productivity-tools.md)和[运营工作台](./operations-workbench.md)。模板仍为候选；2026-09-17 已批准并实现将本人项目复制为独立草稿，详见效率工具。生产协作问题继续见[需求批注](./production-workflow-annotations.md)，暂不开发。

## 产品定位

平台包含客户门户和管理中心。客户提交书籍视频制作资料，管理员接收已提交项目、记录人工跟进，并上传当前最终成品。

产品不是以下系统：

- AI 内容生成平台
- 客户自助生产视频的工具
- 完整内部制作调度系统
- 在线审片和返修协作系统
- 通用工单或事务审批系统

客户界面使用“项目”“需求采集”“提交记录”等业务文案，不出现“API 服务端”“测试工单”或内部技术术语。

## 用户和权限

平台使用真实账号和服务端会话，不提供假身份、默认账号或 Mock Token。

| 角色 | 客户门户 | 管理中心 | 账号管理 |
| --- | --- | --- | --- |
| `customer` | 管理自己的草稿和提交记录 | 无权访问 | 修改自己的密码和头像 |
| `operator` | 按服务端权限提供入口 | 仅处理分配给自己的项目；不可改派负责人 | 个人账号与通知偏好 |
| `admin` | 可访问 | 跟进项目、交付成品、维护用户、组织和配置 | 创建、编辑、停用非所有者账号 |
| `owner` | 可访问 | 拥有全部管理权限 | 首次在服务器本机创建，不可停用或降级 |

详细权限与分配边界见[角色与项目权限](./roles-and-permissions.md)。权限必须由服务端校验。前端隐藏按钮不能代替鉴权。

### 登录和首次设置

- 首次启动只允许从服务器本机创建平台负责人
- 创建负责人后，所有入口统一使用邮箱和密码登录
- 不提供公开注册、自助找回密码或源码内置密码
- 登录状态使用 HttpOnly Cookie，所有修改请求校验跨站请求伪造防护令牌
- 同一账号连续失败 5 次后锁定 15 分钟
- 管理员创建客户或其他管理员账号，并通过安全渠道发送初始密码
- 用户修改密码或管理员重置密码后，旧会话立即失效

### 用户资料和头像

账号至少包含稳定用户 ID、昵称、邮箱、电话、角色、启用状态和可选组织。

- 项目表单自动填充账号昵称、邮箱、电话和组织名称
- 自动填充值仍可在当前草稿中修改，但不会反向修改账号资料
- 普通用户不能自行创建、切换或修改组织
- 一个账号当前最多属于一个组织
- 同一组织的账号不会自动共享项目
- 客户门户点击头像进入个人页面，在个人页面进行头像更换
- 用户可预览、拖动和缩放图片，确认后上传 `512 × 512` PNG
- 未上传头像时，服务端生成首字母、稳定背景色和高对比字体色组成的真实图片
- 前端必须使用 `<img>` 显示头像，不能用 HTML 标签和 CSS 拼装假头像

## 客户门户流程

客户门户完成从草稿创建到最终成品下载的闭环：

1. 客户登录后进入项目看板
2. 客户点击**新建项目**，平台创建归属于当前账号的草稿
3. 客户填写项目和书籍资料
4. 客户配置角色、配音、视觉风格和参考素材
5. 客户检查完整性并确认提交
6. 平台生成不可变提交快照和项目编号
7. 客户在项目详情查看受理状态
8. 管理员上传最终成品后，客户下载当前成品

### 草稿规则

- 草稿只能由创建人查看、编辑和删除
- 草稿不会进入管理中心，也不能被管理员跟进
- 切换步骤、刷新页面或重新登录后，已保存内容不得丢失
- 页面自动保存或用户触发保存时，操作必须直接持久化
- 不允许出现“小保存后还要再点大保存”的嵌套保存流程
- 多窗口写入使用版本号检测冲突，不能静默覆盖新数据
- 删除草稿必须二次确认，并同时处理草稿专属文件

### 六步需求采集

| 步骤 | 主要内容 |
| --- | --- |
| 书籍资料 | 书名、作者、类型、可选卖点与简介、内容语言、时长和源文件；客户资料自动带入 |
| 故事角色 | 故事角色、人物描述和角色参考图 |
| 旁白配音 | 先选择是否需要旁白；需要时配置旁白语言、声音特征、参考音色和发音备注 |
| 视觉风格 | 视觉风格、风格标签和风格参考素材 |
| 参考与创意 | 项目名、品牌、视频目标、截止日期、目标受众、参考文件、补充链接、核心信息和规避内容 |
| 确认提交 | 汇总全部资料、显示缺失项、确认授权声明并提交 |

项目名、卖点、简介及书籍正文默认选填，空项目名采用书名；源文件必填与限制以服务端类别配置为准，见[图书录入](./book-intake.md)。书籍封面、书籍正文、角色图和参考素材必须来自真实上传。无文件时显示缺失状态，不生成虚构封面或素材卡。

故事角色与视觉风格是两个独立业务领域，分别保存完成状态并使用稳定路由。后续退回修改时必须能只退回其中一个领域，不应迫使客户重新进入另一个领域。

配音偏好与参考素材/创意方向同样是两个独立业务领域。退回制作参考时不得要求客户重新选择已经确认的内容语言、声音特征或参考音色。

旁白为可选制作需求，不涵盖角色对白。客户必须明确选择需要或不需要；不需要时隐藏并排除声音配置，本步骤仍可完成。书籍语言、音乐要求和参考资料不受影响。审阅与管理端需显示明确的“不需要旁白配音”。

### 封面识别辅助录入

- 客户主动发起识别；只填入空白字段，不覆盖已有输入。
- 类型可结合书名、副标题、照片文字及可用的书籍上下文，在已配置选项中判断；证据不足时留空，不强制 AI 给出类型。
- 识别失败或没有可用信息时明确提示，保留已有输入；识别结果仍由客户核对。
- 模型服务商维护协议、请求地址、密钥和可用模型；AI 业务从已配置服务商的模型中选择，不另行填写模型。
- 支持 OpenAI 兼容与 Anthropic 协议；接入配置不代表已批准脚本、配音或视频生成业务。

### 定向退回与沟通

- 管理员可选择一个或多个资料单元，分别填写退回原因。
- 客户仅能编辑本轮指定单元；未退回单元不可通过步骤导航进入编辑。
- 双方围绕退回单元交流，消息展示作者名称、头像和正文。客户可以修改，也可以回复解释保留原内容后重新提交。
- 退回前后的资料及轮次保留用于追溯，历史入口仅管理员可见；客户处理当前轮次。
- 资料退回不等于成片返修，不引入通用聊天、审片或成片批准流程。

### 提交规则

- 提交前校验所有必填字段、文件类别、文件大小和文件数量
- 提交请求携带幂等键，重复点击不能产生多个项目
- 提交成功后冻结项目资料和附件快照
- 客户不能自行修改、删除、撤回或复制已冻结项目；只有管理员定向退回后，才能修改指定资料单元并重新提交
- 已提交详情展示提交内容、受理状态、交付状态和最终成品；需补充资料时提供当前退回处理入口
- 客户项目列表必须明确区分草稿与已提交项目

## 业务选项和自定义输入

页面不得把业务选项写死在前端。服务端维护稳定代码、中文名称、英文名称、排序和启用状态。

以下字段采用“后台配置的预设选项 + 客户自定义输入”：

- 视频目标
- 目标受众
- 书籍类型
- 目标语言
- 期望时长
- 投放平台

选择**自定义**后必须出现可编辑输入框。系统保存客户输入的真实值，不能只保存一个名为“自定义”的枚举值。

以下内容也由管理中心配置：

- 品牌线
- 视觉风格和风格标签
- 参考音色、试听文件和双语说明
- 书籍源文件类别
- 创意参考素材类别
- 文件 MIME 类型、单文件大小、数量、是否必填和是否允许链接

管理员修改选项后，客户门户和服务端校验使用同一份配置。已提交快照保留提交时的显示名称和自定义值，不受后续配置变更影响。

系统角色、账号状态、草稿与提交状态、内部跟进状态、优先级和语言代码属于受控系统值，不允许客户自由输入。

## 管理中心

管理中心是正式产品的一部分，只处理已提交项目和平台配置。

### 项目跟进

管理员可以：

- 搜索、筛选和分页查看全部已提交项目
- 查看客户提交的只读资料和附件
- 设置负责人、优先级和制作状态
- 添加仅内部可见的备注
- 手动将状态改为制作中或其他允许状态
- 跳过中间制作节点，直接上传当前最终成品
- 撤回错误的最终成品，并上传替代文件
- 按资料单元退回、沟通并查看退回历史

管理员不能修改客户提交的原始字段、文件或提交快照。草稿不能显示为“待跟进”，也不能进入任何后台统计。

当前跟进状态包括：待跟进、沟通中、已确认、制作中、待客户确认、已完成和已关闭。状态只表达人工跟进进度，不代表系统已实现完整制作工作流。

### 用户和组织

管理员可以：

- 创建客户或管理员账号
- 编辑昵称、电话、角色和所属组织
- 停用或重新启用非所有者账号
- 重置非所有者账号密码
- 创建、重命名和停用组织
- 搜索并分页查看用户和组织

组织采用停用，不物理删除。账号停用可恢复；另有独立的[永久注销](./account-closure.md)流程，清理普通账号资料、保留匿名标记及业务历史，保护当前账号和平台负责人，不能将其理解为任意删除业务记录。

### 系统配置

管理员可以维护业务选项、文件类别、参考音色、AI 接入及运行与网络配置。每次保存必须直接提交当前修改，不设置页面级第二次确认保存。

配置修改必须记录操作人、目标、请求 ID 和发生时间。审计记录不能保存密码、内部备注正文或上传文件内容。

## 国际化要求

客户门户和管理中心必须支持基于路由的国际化：

- 中文路由使用 `/zh-CN/*`
- 英文路由使用 `/en-US/*`
- 两种语言共用组件、数据模型和业务逻辑
- 语言切换保留当前页面、项目 ID、查询参数和表单状态
- 页面文案、错误、状态、配置项、空状态和确认提示必须同时提供中英文
- 日期、时间和数字使用当前 locale 格式化
- 服务端选项保存稳定代码和双语名称，不能只保存一种语言文案
- 新增任何用户可见文案时，必须同时补齐 `zh-CN` 与 `en-US`

## UI 和移动端要求

界面采用紧凑、清晰且面向任务的布局，并使用 Lifewood 品牌配色。

- 页面只显示当前任务需要的标题、说明和操作
- 普通输入框宽度与内容长度匹配，长文本区才使用宽版布局
- 按钮和面板优先使用表面层级、留白和颜色区分，避免依赖装饰性边框
- 相同类型的输入控件使用一致圆角、高度和焦点样式
- 阶段导航用连接线和节点显示当前位置、已完成步骤和待完成步骤
- 头像、封面和素材预览必须来自真实图片资源
- 所有交互支持键盘操作、清晰焦点和可读错误提示
- 移动端把表格转换为可扫描卡片，不能依赖横向滚动完成主流程
- 主操作离开视口后，可以显示右下角浮动按钮，但不能遮挡分页和表单操作
- 移动端分页保持完整顺序和间距，不与浮动按钮重叠
- 顶部导航在窄屏下保留品牌、语言和账号入口，不允许图标溢出屏幕

## 服务端和数据要求

一个正式服务端进程同时托管客户门户、管理中心、认证、业务接口、SQLite 数据库和文件存储。生产运行不依赖 Node.js、Vite、外部测试服务或浏览器本地文件。

- 服务端采用 C#、.NET 10、ASP.NET Core 和 Native AOT 兼容实现
- 数据访问使用 `Microsoft.Data.Sqlite` 和显式 SQL
- JSON 使用 `System.Text.Json` 源码生成
- 禁止运行时程序集扫描、动态代理和依赖即时编译的功能
- 项目、附件、交付文件和审计记录按稳定 ID 关联
- 文件写入使用临时文件、校验和原子移动，失败时不能留下已确认的半成品记录
- 所有客户数据按真实用户 ID 隔离
- 管理操作必须通过服务端权限和审计检查
- 生产数据目录与程序目录分离
- 覆盖安装和升级不能删除数据库、上传文件、交付文件或数据保护密钥

## 安装和运行要求

Windows 和 Linux 发布物都必须自包含，启动正式服务端后即可通过浏览器访问两套前端。

- Windows 便携版通过 `start-server.bat` 选择端口并启动服务
- Windows MSI 在安装时配置端口和生产数据目录
- MSI 覆盖安装沿用并保护已有生产数据目录
- Linux 安装脚本接受明确的端口、数据目录和服务账号配置
- Linux 交互式配置界面属于可选增强，不是当前交付阻塞项
- 服务端直接启动时默认监听 `http://localhost:5000`
- Production 的首次设置只允许从真实本机完成；初始化后可按监听配置提供远程 HTTP 或 HTTPS
- 使用 TLS 终止代理时应显式配置可信代理；公网访问建议使用 HTTPS，但平台不强制协议
- 端口、数据目录和代理地址不得硬编码到前端

## 当前阶段不实现

以下内容不属于当前交付：

- 超出书籍资料辅助识别范围的 AI 推荐和内容生成
- 自动提取生产角色、场景，或生成脚本、分镜、配音及视频
- 内部制作任务拆分、排期、派发和人员负载管理
- 分镜、配音和视频生产节点的自动流转
- 在线审片、时间点评论、成片返修和多版本批准
- 客户绕过定向退回自行修改或删除已提交项目
- 客户自助创建组织或共享同组织项目
- 短信通知和浏览器系统推送（站内通知已实现；邮件能力见 v0.3.16 补充，默认关闭）
- 支付、套餐和订阅
- 通用可视化表单设计器

## 验收基线

当前版本至少满足以下验收结果：

1. 全新安装后，负责人能在服务器本机创建真实账号并登录
2. 客户能创建草稿、恢复草稿、上传真实文件并完成六步提交
3. 账号资料能自动填充客户名称、联系人、邮箱和电话
4. 可自定义字段能保存客户输入，而不是保存“自定义”占位值
5. 提交后默认只读；管理员定向退回后客户仅可处理指定单元并重新提交，退回前后资料可追溯，管理员不能直接改写客户提交内容
6. 普通未提交草稿不进入管理中心；客户自己的列表与数据概览包含本人草稿。已退回项目按退回历史和权限对管理端可见
7. 管理员能创建用户和组织、维护业务选项并跟进已提交项目
8. 管理员能直接上传最终成品，客户能在项目详情下载
9. 客户门户和管理中心的中文、英文路由均可完成主流程
10. 手机端能完成登录、项目填写、上传、提交和成品下载
11. Windows 服务端、便携包和 MSI 不依赖 Node.js 或开发环境开关
12. 覆盖安装后，原数据库、上传文件和最终成品保持可用
13. 封面识别仅补充空白字段，失败不覆盖已有输入；供应商及业务模型绑定可在后台配置
14. 定向退回支持各单元原因和双方回复，未退回单元保持编辑限制，历史仅管理员可见

1. 同一组织的多个账号是否共享项目
2. 除已批准的定向退回外，客户是否可主动发起正式需求变更

4. 原图已有制作节点与职责，仍需确定平台内外边界、项目权限和状态迁移条件

6. 大文件是否改为分片上传或对象存储直传
7. 真实邮件服务、发件域名及启用时间；是否另需其他外部通知渠道
8. Linux 是否必须提供全屏终端配置界面
