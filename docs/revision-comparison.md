# 退回修改前后对比

管理中心项目详情的“退回历史”中，已重新提交的轮次显示变更数量。按资料单元展开后，仅列出发生变化的字段，分别展示退回前与重新提交后的值，并用文字标识新增、移除或修改。长文本默认收起，可展开全文；手机端保留前后两列。界面支持简体中文和英文。

## 对比口径

- 使用该轮次已有的 beforeSnapshot / afterSnapshot；不使用项目当前值，也不从当前配置反推历史名称。
- 覆盖项目与联系人、书籍、角色、视觉风格、旁白、创意方向及附件。枚举与音色采用各自快照中的本地化名称，缺少历史名称时显示“选项信息不可用”，不展示内部 ID。
- 多选项顺序、配置改名、项目版本及更新时间不计为客户修改。旧版旁白设置沿用现有推断规则。
- 角色按稳定身份匹配，新增或移除角色先显示姓名摘要，完整内容仍可展开原始历史记录查看；已有角色逐字段比较，纯排序变化单独显示。
- 附件按稳定身份匹配，同名文件替换显示为移除旧文件、添加新文件。历史下载仍走原有后台鉴权接口。预设图片兼容受控站内路径和旧版 presetId。
- 只有回复而未修改资料时显示“资料内容未变更”；缺少快照或无法解析时显示无法生成对比，不伪造差异。

## 权限与数据

复用现有管理员退回历史接口及项目可见范围；客户接口不返回历史快照。功能仅增加只读展示，不修改快照、项目状态或附件保留规则，不新增数据表。

## 验证

差异计算回归覆盖历史名称、角色插入/排序、同名文件替换、空值、旧旁白、预设图和不安全链接。真实浏览器使用隔离数据库的历史记录验证中英文、桌面与手机布局、长文展开、无变化与快照缺失。复验既有后端退回历史及快照权限测试。
