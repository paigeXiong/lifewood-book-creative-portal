# 客户数据概览

入口为客户顶部导航「数据概览 / Overview」，路由 `/:locale/overview`，支持 zh-CN 和 en-US。项目列表继续保留原有入口与概览；个人资料页不承担项目统计。

## 已实现

- 当前账号项目总数、待我处理、进行中、可下载成品。总数与待处理可以返回对应项目列表；统计卡片反映当前状态，不随月份变化。
- 按浏览器本地时区呈现的月历。日期按钮支持悬停、键盘聚焦及点击，Escape 关闭浮层。未来日期不可选择；本日有标记。
- 固定活动强度档位：0、1、2–3、4–7、8+。颜色与数字共同表示数量，点击后展示该日期的项目和活动时间；每日记录服务端分页，每页 20 条。
- 当月提交资料（首次提交 + 重新提交）与成品发布趋势；图表附可展开数据表。状态构成使用环形图及数字列表。
- 最近更新的 5 个项目；草稿入口进入资料编辑，已提交项目进入详情。完整列表仍在「项目」。

## 数据口径

GET `/api/projects/dashboard?month=yyyy-MM&timeZone=Asia/Shanghai&day=1&page=1` 要求登录且具有 `tasks.read`。服务器从当前登录身份取 ownerId，所有统计与历史明细都按当前项目归属过滤；不接受前端指定其他账号。响应 `private, no-store`。

首次提交通过 SQLite 状态更新触发器记录到 `customer_first_submissions`；首次安装记录 `customer_activity_coverage.started_at`，重启不会改变。不会利用历史迁移推算的 `first_submitted_at`、创建时间或更新时间填造活动。

重新提交读取 `revision_rounds.submitted_at`，发布读取 `project_deliveries.published_at`。撤回后的发布仍属于发生过的活动，但「可下载成品」只统计存在未撤回交付的项目。自动保存、浏览、下载及通知不作为活动。

记录覆盖时间之前（包括启用当天的部分时段）的日期显示历史可能不完整。没有留存记录时使用斜纹及破折号，不表现为已确定的零；趋势不跨未知日期连线，不给未知单项绘制零值点。有留存记录时显示已知数量。

每个本地自然日分别换算 UTC 起止边界，以处理夏令时、跨月和午夜偏移。月历、趋势、每日分页使用相同边界。查询使用延迟只读事务与月份范围过滤，避免占用 SQLite 写锁及装载整个历史。

没有实现平均交付耗时、响应耗时、准时率等分析，也没有新增真实生产流程或交付承诺。
