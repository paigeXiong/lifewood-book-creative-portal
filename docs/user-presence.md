# 用户在线状态与活跃数据

后台用户页新增状态、最近活跃、筛选统计和按需详情，支持中英文。在线数据仅向具备 `admin.users.manage` 权限的账号提供；运营与客户不能查看用户目录或详情。

## 状态口径

- 在线：最近 120 秒内收到有效心跳，至少一个页面可见且最近 5 分钟内有真实用户输入。
- 离开：仍有有效心跳，但页面被隐藏或超过 5 分钟没有输入。
- 离线：没有有效心跳，或账号被停用、会话版本失效。
- 心跳每 30 秒发送，用户列表每 15 秒刷新，并在本页心跳成功后立即同步，丢弃心跳前发起的旧列表响应。关页/断网可能要等心跳超时才显示离线；后台节流也可能使长时间隐藏的页面离线。
- 多标签页和多设备按账号去重，只要一个页面满足在线条件就算在线。退出或切换账号结束当前浏览器会话，其他设备不受影响；迟到心跳不能恢复已结束会话。保存到切换账号列表中的账号不算在线。
- 同一登录会话刷新页面时继承最近 5 分钟内的真实活跃时间，不延长该时间；隐藏的页面仍显示离开。地址栏或应用侧栏获得焦点不会把仍可见的页面误判为离开；鼠标移动等真实输入计为活跃。此短期记录不跨设备、登录会话或失效的会话版本，退出时清除。
- 自动恢复页面、通知轮询、SSE 和被脚本派发的输入事件不计为用户操作。登录时间仅记录成功的密码登录、添加账号和初始化，不把会话恢复、账号切换或修改资料记为新登录。

## 数据展示

列表显示姓名旁的状态和最近活跃。按在线状态、组织、启停、角色和搜索条件过滤后，再统计及分页；卡片数字随当前筛选变化。今日活跃按查看者本地当天零点计算，按账号计数。

点击姓名查看最近登录、最近活跃、创建时间、所属组织、角色，以及已提交与待处理项目数。已提交包含该账号拥有的正式提交项目及有退回历史的项目；待处理包含本人待补资料的项目、本人负责且待跟进/跟进中的项目。普通未提交草稿不计入。

服务端记录时间，不接受客户端上报任意活动时间或其他账号身份。不记录页面路径、操作内容、IP 或设备详情。历史时间从功能启用后开始积累，缺失显示“暂无记录”；服务器重启会清空连接状态但保留最近登录、活跃记录。短期连接记录过期清理，结束会话标记最多保留 31 天以覆盖最长登录有效期。

## 接口与保护

- `POST /me/presence`：当前账号的页面心跳；`DELETE /me/presence?tabId=...`：离开当前页面。
- `GET /admin/users`：新增 `status`、`organization`、`enabled`、`todayStart` 筛选，响应包含统计。
- `GET /admin/users/{id}/details`：受用户管理权限保护的详情。

心跳保留 CSRF、账号绑定、会话有效性校验，使用独立限流避免消耗项目写入额度。每账号最多 64 条连接记录。登录和活跃记录独立于用户资料更新时间。
