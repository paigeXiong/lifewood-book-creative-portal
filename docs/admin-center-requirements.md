# 管理中心需求说明

## 1. 产品定位

管理中心是正式产品的一部分，用于平台内部人员接收和跟进客户提交的书籍影像项目。它不是可移除的测试控制台，也不修改客户已经提交的原始需求资料。

平台形成两个相互隔离的使用面：

- 客户门户：创建草稿、提交项目、查看自己的项目。
- 管理中心：创建用户、查看全部客户项目、分配负责人、更新跟进状态并记录内部备注。

## 2. 账号与权限

平台包含三种角色：

| 角色 | 能力 |
| --- | --- |
| `owner` | 平台所有权限；首次部署时创建，不能在管理中心停用或降级 |
| `admin` | 访问管理中心、管理项目、创建和停用用户、维护业务配置 |
| `customer` | 访问客户门户，只能读取和提交自己的项目 |

账号规则：

- 不提供公开注册；客户和后续管理员账号由管理中心创建。
- 用户使用唯一邮箱和真实密码登录。
- 密码继续使用 ASP.NET Core `PasswordHasher<TUser>` 存储。
- 用户采用启用/停用，不物理删除，保证项目归属和历史记录完整。
- 停用账号立即失去现有会话和重新登录能力。
- 用户可以在头像菜单中修改自己的密码；成功后必须重新登录。
- 客户门户的头像入口统一进入个人页面；头像编辑可选择常见图片、拖动缩放裁剪后上传或恢复默认头像；客户端统一输出 512×512 PNG，未上传时由服务端生成首字母头像图片，不使用 HTML 元素伪装头像。
- 管理员可以重置非所有者账号密码，重置后该账号原有登录会话立即失效。
- 所有 `/api/admin/*` 接口必须在服务端检查管理员权限，前端隐藏入口不能代替鉴权。

## 3. 项目跟进

客户提交内容与内部跟进信息分离存储。管理员不能改写客户提交的项目、书籍、角色、声音、创意方向和附件元数据。

内部跟进字段：

- 跟进状态：待跟进、沟通中、已确认、制作中、待客户确认、已完成、已关闭。
- 优先级：低、普通、高、紧急。
- 负责人：启用状态的所有者或管理员。
- 内部备注：仅管理端可见，记录作者、内容和创建时间。

项目管理页必须提供服务端搜索、筛选和分页；默认采用左侧项目列表、右侧详情与跟进操作的紧凑布局。

### 3.1 已批准的定向退回

管理员可选择多个资料单元并分别填写原因，客户在指定单元修改或回复说明后重新提交。双方消息展示名称、头像和正文，退回历史仅管理员可见。这是需求资料补充，不引入成片审阅、批准或通用聊天。

### 3.2 已批准的 AI 接入配置

服务商配置与 AI 业务绑定分开。服务商维护名称、协议、请求地址、密钥及可用模型，支持 OpenAI 兼容与 Anthropic 协议；业务配置选择服务商及其已有模型。当前已批准业务为书籍资料辅助识别，后续生产 AI 业务不因存在配置入口而自动纳入范围。

## 4. 用户管理

管理员可以：

- 按姓名、邮箱和角色搜索用户。
- 按姓名、邮箱或所属组织搜索用户。
- 创建客户或管理员账号。
- 创建账号或编辑账号时分配一个可选的所属组织。
- 编辑用户昵称、角色和所属组织；所有者角色和启用状态仍受保护。
- 启用或停用非所有者账号。
- 查看账号角色、所属组织、状态和创建时间。

界面不展示任何现有密码或密码哈希；所有密码写入均需要 CSRF 校验。

## 4.1 简化组织模型

- 组织是具有稳定 ID、名称、启用状态和成员数的独立实体，不使用用户自由填写的临时文本代替。
- 管理员可以搜索、分页、新增、重命名和停用组织；组织不物理删除。
- 停用组织保留已有用户归属和历史记录，但不能再分配给新账号。
- 普通用户只在账号菜单中只读查看所属组织，不能自行创建、切换或修改。
- 首期一个账号最多属于一个组织，不建设部门树、邀请、组织管理员或多组织成员关系。
- 同组织账号是否共享项目仍属于后续业务决策；当前项目可见范围继续按用户本人隔离，不因组织相同而自动扩展。

## 5. 国际化

- 管理中心必须具有独立的 `/zh-CN/*` 和 `/en-US/*` 路由。
- 导航、状态、优先级、角色、表单、错误、空状态和确认提示必须同时提供中英文。
- 日期和时间按当前页面语言格式化。
- 后续配置管理中的业务选项必须保存稳定 ID 和中英文名称，不能只保存某一种语言的显示值。

## 6. 当前实现阶段

已完成：真实管理员鉴权、用户创建与停用、简化组织管理与用户组织分配、密码修改与重置、跨客户项目查询、项目详情、负责人、状态、优先级、内部备注、管理员附件读取、最终成品快捷交付与撤回、客户侧跟进状态展示、参考音色标签配置、试听文件上传与移除，以及项目基础、角色、视觉风格和配音属性共 20 组业务选项的双语可视化配置。

当前业务选项均由服务端统一提供；已纳入系统配置的分组支持新增、双语编辑、排序和停用。书籍源文件与创意参考素材类别还支持配置 MIME 类型、单文件大小、文件数量、必填和链接属性，上传控件与后端校验共用同一配置。

已完成统计概览：只统计客户已正式提交的项目，提供已提交项目总量、待分配项目、账号数量、提交状态、跟进状态、优先级分布和最近更新项目。客户草稿不进入管理后台，也不能被查看、分配、修改跟进状态或添加内部备注。

正式提交会把后台工作流初始化为“待跟进、普通优先级、未分配”，并以提交时间作为首次跟进时间。旧版本中误加到草稿上的跟进值不会进入正式流程；已提交历史数据仅在跟进时间早于提交时间时执行同样的幂等修复，提交后的正常跟进不受影响。草稿时期误加的备注保留在数据库中用于追溯，但不会显示在正式提交后的项目详情中。

已完成操作审计：成功的用户管理、项目跟进、最终成品交付和业务配置写操作会保存操作人快照、动作、完整作用域目标标识、请求 ID 和发生时间；不保存密码、备注正文、文件内容或表单载荷。管理员可按操作人、目标 ID、请求 ID、操作类型和日期范围进行服务端搜索、筛选与分页查询。数据库短暂繁忙时，审计事件先写入本地持久化待写队列，并在启动、下一次写入或查询时自动幂等重放；只有审计事件已写入数据库或持久化队列后，平台才提交对应的成功响应。

若数据库和本地待写队列同时发生不可恢复的存储故障，业务变更可能已经完成，但平台会返回失败而不会确认成功；运维应依据响应中的请求 ID 检查审计日志后再决定是否重试，避免重复执行非幂等操作。


### 预设角色配置（已实现）

- 入口：系统配置 → 预设角色，路由 `/:locale/settings/characters`。
- 管理中英文角色名、故事作用、角色描述、外貌、服装、表情气质、声音提示；角色类型、年龄段与性别使用后台表单选项。
- 支持添加、编辑、排序、启用/停用，以及上传替换 JPG、PNG、WebP 参考图片（最大 5 MB）。最多保留 100 个预设，同时启用最多 12 个，对齐客户表单角色上限。
- 初始迁移保留原有 7 个预设。新建项目复制已启用角色的本地化资料和图片地址；管理员后续修改不会改动旧项目。旧图片保留供历史项目使用，并包含在平台数据目录备份中。
- 配置写入需要 `admin.config.manage` 权限和 CSRF 校验，使用版本检查防止并发覆盖；成功的配置和图片更新记入操作审计。
- 图片在资料保存后上传；图片上传失败时保留编辑内容与已保存版本，可重试。


### 表单选项停用与移除（已实现）

- 列表直接启用/停用，默认查看启用项，可通过状态筛选查看停用项或全部项。
- 删除需再次确认，并校验管理员权限、CSRF 和选项版本。被当前项目、退回历史、预设角色或音色引用的选项不可删除，只能停用。
- 移除采用不可见的删除标记，保留审计所需元数据并防止内置选项重启后重建；客户选项与后台列表均排除已移除项。数据库写入约束防止并发保存新增对已删除项的引用。


### 文件类别、预设角色和参考音色删除（已实现）

- 三个列表均提供删除按钮，使用平台确认弹窗和中英文提示；失败保留列表并刷新版本以便重试。
- 文件类别、参考音色被项目或退回历史引用时禁止删除，可在编辑中停用；删除与引用检查在同一写入事务内，数据库保护并发保存。
- 预设角色用于创建项目时复制资料，删除预设不改变已有项目的角色和图片。
- 删除保留数据库标记及原图片、音频文件，阻止标识复用、旧编辑器恢复及启动初始化重新添加。已删除的预设或音色不再占用表单选项；项目和历史引用仍受保护。
- 删除接口校验管理权限、CSRF 和配置版本，并记录操作审计。
