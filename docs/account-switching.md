# 账号切换

2026-09-08：客户与管理端右上角账号菜单支持已验证账号列表、直接切换、添加账号和从当前设备移除账号。添加时验证账号密码，成功后切换；已添加账号在登录有效期内无需再次输入密码。最多保存 5 个账号；普通登录超出上限时移除最早到期的快捷会话。未验证的账号不能按用户 ID 直接切换。

- 不保存密码。浏览器只持有 HttpOnly、SameSite=Strict 的随机设备标识，服务器仅保存标识哈希、账号 ID、会话版本和有效期。HTTPS 下 Cookie 同时启用 Secure。
- 未勾选“保持登录”的账号使用额外的浏览器会话 Cookie，最长 8 小时；勾选时最长 30 天。切换不延长原有快捷会话期限。密码重置、账号停用、会话版本变更或到期后不能使用旧快捷登录。
- 从设备移除不会删除账号或项目。普通退出只撤销当前账号的快捷会话，保留记住的身份；独立的“清除本机全部账号”会撤销全部快捷会话、移除记录并退出，其他设备不受影响。
- 切换前检查未保存内容，成功后清空页面查询缓存并重新加载目标首页；后台切到客户账号时进入客户门户。
- 常规 API 和交付上传绑定页面所属账号，服务器拒绝旧页面以新账号发出的请求。通知 SSE 绑定账号；页面通过窗口激活及定时检查感知会话变化，暂停操作、关闭旧通知流并提示刷新。
- 首次认证、账号切换沿用认证限流和 CSRF 保护。界面支持中文、英文及窄屏。

2026-09-19：记住的身份与有效登录会话分表保存，设备标识保留一年，不延长任何登录权限。会话到期、浏览器重启或版本失效后，列表显示“需重新登录”，需重新验证密码。清理 Cookie 或更换浏览器后仍需重新添加。添加接口与界面均按记住的身份计算五个名额，先移除再添加；普通密码登录仍沿用容量上限。
