# 客户表单的手机与键盘操作

## 当前行为

- 小屏填写页面的返回、回首页、继续操作紧凑排列。主操作独占下行，只有两个操作时并排显示；手机与小平板上的操作按钮至少 44px 高。
- 380px 以下收紧品牌区域，保留通知、公告、后台和账号入口，避免账号按钮把页面撑出横向滚动。
- 必需文件缺失时聚焦对应上传入口。可见上传入口支持键盘打开文件选择，隐藏文件输入不额外进入 Tab 顺序。
- 校验失败统一定位可用控件：自动展开折叠区域，跳过隐藏和停用选项，支持自定义时长、角色分组及角色内字段。
- 选项获得键盘焦点时将完整标签滚入可见范围；首次报错会清空选项搜索，避免错误选项仍被过滤。
- 错误提示和操作文案沿用现有中英文资源。

## 已验收范围

`tests/e2e/mobile-workflow.spec.ts` 使用真实服务器草稿，覆盖五个填写步骤、两种语言及 320×740 / 768×480 视口，共 20 个组合。检查页面和按钮边界、操作按钮尺寸、底部高度、步骤展开、账号菜单键盘打开/关闭及焦点返回、上传入口和缺文件定位。

同时执行上传恢复与编辑冲突浏览器回归。单元测试覆盖隐藏/停用选项、折叠字段、自定义时长、角色分组、选项滚动与过滤复位。

上述验收使用 Chromium 视口模拟；未覆盖真实 iOS/Android 键盘、相机或系统文件选择器差异。
