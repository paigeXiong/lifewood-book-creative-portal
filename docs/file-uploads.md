# 客户文件上传与恢复

书籍资料、角色参考图、风格参考图和制作参考文件共用逐文件状态展示，适配简体中文、英文和窄屏。

- 进度来自实际网络传输；传输到 100% 后显示服务器处理中，收到保存成功响应后才进入已上传列表。
- 每次选择的文件顺序上传，使用上一份成功结果的项目版本。结果不确定时暂停后续队列；重试成功后继续剩余文件，不重传已经成功的文件。
- 可取消正在传输或等待的文件。失败或取消的文件可单独重试；移除失败记录前会核对服务器，避免遗漏已经保存但响应丢失的附件。
- 重试沿用同次上传标记。服务端将标记限定于用户和项目，核对目标、文件元数据和内容 SHA-256，重复请求返回已有附件，不重复增加项目版本或占用容量。旧客户端未发送标记时仍可上传。
- 上传重放或状态核对发现其他窗口修改了正文时，进入已有版本冲突处理，不自动覆盖。上传中的本地文字修改保留。
- 单张照片转换失败不会阻止同批其他有效照片上传；失败照片保留单独重试入口。
- 离开页面或切换任务会停止旧队列及照片处理后的派发，旧请求不能写入新任务的界面。

队列和待重试文件只保存在当前页面内存。刷新或关闭页面后需重新选择未完成的文件；本功能不是大文件分片或跨刷新断点续传。取消传输也不等于删除已经保存的附件，后者仍使用文件列表的删除操作。

验证涵盖双语状态与操作、上传进度和取消信号、并发重复请求及内容不一致、用户隔离、丢失响应后的队列恢复、正文冲突、照片部分失败和离开页面。浏览器场景使用隔离数据与独立客户账号，服务器真实保存文件后人为丢弃首次响应，确认重试没有重复附件；同时检查 1366px 中文与 390px 英文布局。
