# 成品交付恢复与客户进展

本轮改动尚未发布，沿用当前单份有效最终成品规则，不增加成片审批或多版本生产流程。界面同时支持简体中文、英文与手机端。

## 上传结果恢复

- 每次成品上传生成稳定标识，重试沿用原标识、文件与说明。服务端按操作账号和项目隔离该标识，比较文件名、类型、长度、说明及 SHA-256；不同内容不能重用同一标识。
- 上传到 100% 后显示服务器处理中，只有收到保存结果或核对到已保存记录才确认完成。重复请求不再新增文件、交付记录或交付通知。
- 取消、断网或返回内容异常后，先调用只读结果接口。核对失败时仅允许再次检查；确认未记录后可重试原文件。一次检查的“未记录”不承诺原请求已结束，因此重试仍使用相同标识。
- 查询与上传最终写入、撤回按项目串行协调。撤回后的记录仍能核对，但重试不会恢复已撤回成品。当前项目只能有一份有效交付。
- 等待结束与文件处理完成后重新检查会话和权限。旧客户端不传上传标识仍兼容原交付接口。
- 上传和说明保存在当前页面内存，关闭弹窗可继续核对；离开项目、刷新或关闭页面后不保留本地文件。本功能不提供跨刷新断点续传。

接口：`GET /api/admin/projects/{id}/deliveries/uploads/{uploadId}`；原交付 multipart 接口新增可选 `uploadId`。数据库增量增加 `project_deliveries.content_sha256`，保留旧交付记录。

## 客户项目详情

详情顶部并列展示当前跟进状态、下一步说明与成品交付，手机端改为上下排列；提交资料位于下方，可从顶部直接定位。跟进状态取自服务端，下载状态取自当前有效交付，不根据“已完成”状态推测文件一定存在。页面保持打开时定期刷新，已撤回成品移除下载入口，原文件接口继续拒绝访问。

## 验证范围

- 后端：同一请求并发提交、文件及说明冲突、单份有效交付、撤回后的重试、客户越权查询、磁盘临时文件清理。
- 前端：响应丢失、结果查询失败、原文件重试、取消后核对、撤回后禁止重发、重复点击及切换项目的迟到响应。
- 浏览器：中英文提交、定向退回、客户修改与重新提交、交付回执丢失、结果核对、真实文件下载及撤回；桌面和手机检查详情顶部布局。
