# 平台公告（2026-09-07）

入口：管理后台 → 系统配置 → 公告。拥有 `admin.config.manage` 权限的账号可管理公告。

## 发布步骤

1. 新建公告，选择登录前或登录后。
2. 选择全部账号或指定范围。指定范围可选语言、组织，二者同时选择时取交集；组织可多选，复用组织管理页的搜索和分页。
3. 填写一份标题和正文，可使用任意语言，也可在同一条公告中同时写入多种语言；不要求翻译或分开发送。填写公示天数（默认 30，支持 1–3650 天），从实际发布时起按每 24 小时计算。正文按纯文本显示，不执行 HTML。
4. 预览并保存草稿，在列表确认发布。发布锁定内容和收件范围；再次通知需复制为新公告。支持下架，并记录管理审计。

## 登录前

公开公告，只按当前页面语言筛选，不支持组织定向。每次进入登录页重新获取公告；本次关闭后不重复弹出。切换页面语言会重新获取相应公开公告。

## 登录后与个人历史

- 发布时为匹配的现有启用账号保存收件记录。未设置语言偏好的账号按 `zh-CN` 匹配。
- 收件人是发布时的快照：之后变更语言或组织不会混入其他组织公告；新建账号不追溯接收旧公告。未来生效的公告同样按发布时账号范围确定收件人。
- 新公告显示于一个弹窗。关闭时记录当前已加载公告的关闭状态，按账号持久保存，换设备也不再提醒；未加载公告不被批量标记。
- 顶栏“公告”可打开个人历史，按发布时间倒序，向下滚动自动分页，同时保留“加载更多”按钮。
- 过期的个人公告停止弹出，但保留个人历史；下架的公告不再出现在客户侧。未到开始时间的公告不可见。
- 如果关闭状态保存失败，显示重试入口，并允许先关闭窗口；未成功保存的公告可能在下次登录时再次提醒。

## 范围与验证

本功能不包含邮件、短信、评论、阅读统计或生产协作通知。当前实现不向任何真实账号自动发布示例内容。

已验证：6 项服务端公告测试（含真实 HTTP 发布权限与关闭流程），2 项中英文前端公告回归；管理端原有 57 项测试通过，两套前端构建通过。独立审查发现的组织选择导航状态及公告缓存漏弹问题已修复。浏览器检查确认组织搜索后可保留选择和正文输入，390px 编辑器无横向溢出。

新增真实浏览器验收覆盖后台双语公告保存与发布、登录前按语言展示及再次进入弹出、390px 视口滚动加载 23 条个人公告、关闭后刷新不再弹出、手动打开个人历史。

## 后台维护补充

列表支持按状态和展示位置组合筛选。点击发布会读取当前草稿版本的预计收件人数，再请求确认；公开公告不显示账号人数。未发布草稿支持二次确认删除，服务端校验版本和状态，已发布／已下架公告不能通过草稿删除接口移除。相关权限、筛选、人数及删除回归和浏览器流程已通过。

## 单份内容与语言偏好

新公告只保存一份标题和正文，界面切换中英文不会改变公告原文。管理员可直接发给全部账号，或按语言偏好及组织选择收件范围；只有希望分别发送不同内容时才需要另建公告。界面按钮、校验和提示继续支持中英文。已有双语公告仍按当前界面语言显示；旧草稿仅调整范围或时间时保留原双语内容；编辑标题或正文、复制为新公告时，以当前界面语言的内容作为单份正文，编辑器会显示提示。

本次单份内容验收通过：10 项公告服务端测试、57 项管理端测试、两套前端构建，以及真实浏览器流程（单份发布、英文编辑器、语言定向、旧草稿保留与转换、390px 布局、客户历史公告）。

## 公示天数

管理端以公示天数替代开始、结束时间。新建默认 30 天，可填 1、60 等正整数；发布时开始计时，到期后个人公告不再自动弹出但保留历史，公开公告停止展示。草稿等待时间不计入公示期，复制公告重新发布会重新计时。旧已发布公告继续使用原到期时间，旧草稿保存时采用界面显示的公示天数。
